# Then

Thenは、Windowsで使える縦書きのテキストエディタです。

縦書きでタイプライタースクロールができて、ファイルを作った直後から入力している行が画面の中央にある。そういうエディタが欲しかったんですが、自分の条件に合うものが見つからなかったので作りました。

基本的な執筆機能に加えて、アイデアをメモしたり、プロットを組んだり、資料を参照したりする機能も備えています。原稿はMarkdownまたはテキストファイルで保存され、PDFやWord（DOCX）形式への書き出しもできます。

[ダウンロードはこちら](https://github.com/maybefix/Then/releases/latest)

## インストール

Windows x64向けに配布しています。[GitHub Releases](https://github.com/maybefix/Then/releases/latest)から、`Then_*_x64-setup.exe` という名前のインストーラーをダウンロードして実行してください。

現在のインストーラーにはコード署名をしていないため、Windows SmartScreenの警告が表示される場合があります。ダウンロード元が、このリポジトリのGitHub Releasesであることを確認してください。

### 旧版を使っている方へ

v0.6.6では、共通資料と共通Canvasのサポートを終了します。

更新後に初めてThenを起動すると、旧版の共通資料、共通Canvas、そのゴミ箱と中間稿が削除されます。自動でバックアップは作られないので、必要なものは**更新前に旧版のThenから書き出すか、Then外へコピーしてください**。作品フォルダ内の資料やCanvas、中間稿は削除されません。

詳しくは[更新時の注意事項](docs/RELEASE_NOTES_NEXT.md)をご確認ください。

## 使い始めるには

初回起動時に、ライブラリを作る場所を指定します。ライブラリは、複数の作品をまとめて管理するためのフォルダです。

1. ライブラリの名前と作成場所を決めます。
2. 「＋ 新しい作品」から作品を作ります。既存の原稿フォルダがある場合は、作品として取り込めます。
3. 作品内に原稿ファイルを作り、書き始めます。

本文は編集後に自動保存されます。保存先が決まっていない新規原稿では、ファイル名と保存先を指定してください。画面下部で保存状態を確認できます。

このあとご説明するIdeaやPlot、Canvasなどは、必要になったときに使ってもらえればと思います。

詳しい操作は[操作マニュアル](docs/USER_MANUAL.md)をご参照ください。

## 原稿を書く

縦書きと横書きを切り替えて書けます。
本文のフォント、文字サイズ、行間などは設定から変更できます。

Thenを作るきっかけにもなったタイプライタースクロールは、入力している行を画面内の一定位置に保つ機能です。書き進めると原稿の表示位置が動き、入力行が同じ場所に留まります。固定する位置は変更できるので、中央より少しずらして使うこともできます。

本文を連続して表示する方式のほか、ページに区切って表示する方式もあります。
行番号、現在行のハイライト、会話文の色分けなども簡易的ですが実装しています。必要に応じて設定してください。

### 見出しやルビを使う

Markdownの見出し、太字、引用、リスト、表などに対応しています。日本語の原稿向けに、ルビ、圏点、縦中横、行揃えの記法も用意しています。

たとえば、ルビと縦中横は次のように書けます。

```text
[東京(rb,とうきょう)]
憂鬱《ゆううつ》
[21(tcy)]
```

ルビはThen独自の記法と青空文庫形式の両方を使えます。記法を毎回手入力しなくても、文字を選択してコマンドから適用できます。

原稿に残しておきたいメモや、いったん外しておきたい文章はコメントにできます。

```text
// ここの会話は後で書き直す
```

コメントは編集画面で確認できますが、文字数や校正、書き出しの対象には含まれません。一時的に非表示とすることもできます。

記法の一覧は[Then独自記法の手引き](docs/THEN_SYNTAX_GUIDE.md)にまとめています。

### 原稿の構成を変える

Markdown記法で見出しを付けると、左サイドバーのアウトラインから各見出しへ移動できます。

左サイドバーで見出しをドラッグすると、配下の文章ごと移動できます。同じファイルの中で順序を変えるだけでなく、別のファイルへ移したり、一つのセクションを新しいファイルとして切り出したりすることも可能です。

章ごとにファイルを分けていて、途中で構成を変えたくなったときなどに使えます。

## アイデアや資料を整理する

本文を書くだけでなく、調べたことや思いついたことを集めて、構成を考えるための機能も作っています。

### Ideaと資料

Ideaには、断片的なメモを残せます。思いついたものを追加していき、後からスレッドという単位で束ねたり、並べ替えたりできます。

資料として取り込めるのは、テキスト、Markdown、画像、PDFです。Ideaと資料は同じスレッドに並べられるので、設定のメモと参考資料を一緒にまとめておくこともできます。

Ideaや資料は、本文の上に浮かぶカードとして開けます。人物設定や参考画像など、何度も見返すものを開いておきたいときに使ってください。

### Plot

章とセクションのカードを使って、文章の構成を考える機能です。

セクションに展開を書き、順番を入れ替えながらプロットを組めます。セクションが増えてきたら、章を作ってまとめると見通しがよくなります。資料を関連付けておくこともできます。

### Canvasと中間稿

メモや資料のカードを自由に並べられる画面です。カード同士を線や矢印で結んだり、グループにまとめたりできます。一つの作品に複数のBoardを作れるので、人物関係と物語の展開を別々に整理する、といった使い方もできます。

Canvasで整理したテキストカードは、IdeaやPlotへ送れます。また、カードに順序を付けて、一続きの「中間稿」にする機能もあります。

中間稿はCanvasのカードを並び替えて一続きのテキストにする機能です。生成後に編集できますが、その編集が元のカードや本文に自動で反映されるわけではありません。Canvas上で考えたものを文章として読み直し、必要なところを原稿へ持っていくためのものです。

## 書いた文章を見直す

各種ガイドラインに沿った日本語の校正機能があります。表記ゆれ、重複表現、冗長表現、約物、敬語などを確認し、指摘された箇所へ移動できます。置換候補がある場合は、その場で置き換えることもできます。

人物名や作品内の用語は、校正辞書に登録できます。会話文を校正の対象から外すなど、ルールの設定も変更できます。

校正処理はアプリ内で行います。原稿を外部の解析サービスへ送信する仕組みではありません。

### 書き直す前の状態を残す

チェックポイントを作ると、作品内の原稿と並び順を保存点として残せます。

大きく書き直す前や、構成を変える前などに、名前やメモを付けて保存しておくと使いやすいと思います。現在の原稿との比較や、保存点同士の比較ができ、作品全体でも、選んだファイルだけでも復元できます。

復元するときは、その直前の状態も自動で退避します。

ただし、チェックポイントはあくまで原稿についてのバックアップです。画像やPDFなどを含む作品フォルダ全体のバックアップではありません。フォルダ全体のバックアップは別途取ってください。

## 原稿を書き出す

複数の原稿ファイルを選び、順番を指定して、一つの文書にまとめられます。

PDFとDOCXの書き出しでは、用紙サイズ、縦書き・横書き、余白、フォント、段組みなどを設定できます。表紙や目次、ヘッダー、フッター、ノンブルも付けられます。出力用のプレビューで確認してから保存してください。

PDFの組版にはVivliostyleを使っています（ライセンスに関しては、この文の「第三者ライセンス」をご覧ください）。処理はローカルで行います。

カクヨム、小説家になろう向けのテキスト書き出しもあります。投稿先に合わせてルビや圏点の記法を変換し、クリップボードへコピーするか、テキストファイルとして保存できます。投稿サイトへのアップロードは、ご自身で行ってください。

## データの保存場所

原稿は、作品フォルダ内の `.md` または `.txt` ファイルとして保存されます。Then専用の形式に変換されるわけではないので、ほかのエディタでも開いて編集できます（先述の通り、一部記法はThen独自のものになります）。

IdeaやPlot、Canvas、資料、チェックポイントなどの管理データは、作品フォルダ内の `.then` フォルダに保存されます。原稿だけをコピーすると、これらのデータは一緒に移らないので、作品を移動するときやバックアップを取るときは、`.then` を含めて作品フォルダ全体をコピーしてください。

`.then` の中身は、通常はThenから操作してください。

テーマや最近開いたライブラリなど、アプリ自体の設定は端末ごとに保存されます。

## テーマとプラグイン

ライト・ダークともにたくさんのテーマを用意しています。基本的には配色の違いですが、角丸など、形状が異なるテーマもあります。本文のフォントとUIのフォントは個別に設定できます。

テーマについては、現時点では私（MaybeFix）が用意したもののみとなりますが、今後はプラグイン同様に各自で作成できるようにしたいと考えています。

プラグインにも対応しています。右側のツール画面や独立した作業画面、選択した文章に対するコマンドなどを追加できます。

プラグインを作りたい方は、[Plugin API v1](docs/PLUGIN_API_V1.md)と[サンプル](docs/plugin-example/README.md)をご覧ください。

## 開発する方へ

Tauri v2、React、TypeScript、Viteを使っています。Windowsでの開発には、Node.js、npm、Rustと、TauriのWindows向けビルド環境が必要です。

依存パッケージをインストールして、開発版を起動します。

```powershell
npm install
npm run tauri:dev
```

ビルドする場合は、次のコマンドを使ってください。

```powershell
npm run build
npm run tauri:build
```

NSISインストーラーは `src-tauri/target/release/bundle/nsis/` に生成されます。

## 不具合の報告・要望について

不具合や要望は、[GitHub Issues](https://github.com/maybefix/Then/issues)へお願いします。

不具合の場合は、Thenのバージョン、問題が起きるまでの操作、実際に起きたことが分かると確認しやすいです。スクリーンショットを添付する場合は、原稿や資料の内容が写っていないか確認してください。
