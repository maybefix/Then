# Then

日本語の縦書き執筆に特化した、Windows向けデスクトップエディタです。

Markdown / テキストファイルをそのまま原稿として扱いながら、本文執筆、構成管理、資料参照、保存点の比較・復元、PDF / DOCX出力までを一つのワークスペースで行えます。

- 開発中のバージョン: `v0.6.2`
- 対応環境: Windows x64
- 技術構成: Tauri v2 + React + TypeScript + Vite + Tiptap / ProseMirror
- 最新の公開版: [Then v0.6.0](https://github.com/maybefix/Then/releases/tag/v0.6.0)

- プラグイン開発: [Then Plugin API v1](docs/PLUGIN_API_V1.md)
- Plugin API v1は複数の右ツールビュー、固有アイコン付き作業画面、画面遷移しない全面モーダル、選択時の右クリックコマンド、ステータスバー項目を追加できます。
- サンプル: [Selection Notes](docs/plugin-example/) / [Ticket](docs/ticket/)

変更履歴は[GitHub Releases](https://github.com/maybefix/Then/releases)を参照してください。

## 主な機能

### 縦書き本文エディタ

- Tiptap / ProseMirrorと独自ASTを組み合わせた縦書き編集
- 入力位置を画面内の一定位置に保つタイプライタースクロール
- タブごとのカーソル位置と表示位置の復元
- 見出し、引用、リストなどのMarkdown表示
- 太字 `**…**`（`Ctrl+B`）
- 圏点 `[…(em,goma)]`（`Ctrl+I`）
- ルビ `[…(rb,ルビ)]` と青空文庫形式 `｜…《ルビ》`
- 縦中横 `[…(tcy)]`
- 行揃え `[(al:start|center|end)]`
- 見出し1〜6（`Ctrl+1`〜`Ctrl+6`）と解除（`Ctrl+0`）
- `Ctrl+P` で開くコマンドパレット
- 改行記号、表示上の折り返しに沿った行番号、現在行ハイライト
- `「」` で囲まれた会話文の色分け
- 文字数、保存状態の表示

### ワークスペースとファイル管理

- 起動ポータルから最近使ったワークスペースを再開
- `.md` / `.txt` ファイルの作成、オープン、保存、別名保存
- 複数ファイルをタブで同時編集
- ファイルツリーとナビゲータ表示、Ctrl+クリックで選択した複数ファイルの一括移動
- 見出しアウトラインからのジャンプとセクション移動
- ファイル／フォルダの作成、リネーム、移動、並び替え、Trashへの削除
- パンくずによるフォルダ階層の移動
- 現在のファイルまたはプロジェクト全体を対象とした検索・置換

### Idea・プロット・キャンバス

- Ideaをスレッドと断片に分けて整理
- `Ctrl+Alt+I` で本文画面から素早くIdeaを追加
- Ideaの検索、並び替え、本文へのダブルクリック／ドラッグ&ドロップ挿入
- 章とセクションのカードによるプロット管理
- セクション番号の自動付与と折りたたみ状態の保存
- Ideaや資料を自由配置し、線でつなげられるIdea Board
- Idea Boardの複数Boardを並べ替え、ゴミ箱へ移動・復元
- プロジェクト専用と全ワークスペース共通の保存範囲

### 資料

- テキスト、Markdown、画像、PDFを資料として登録
- プロジェクト資料と共通資料の切り替え
- 資料の検索、プレビュー、コピー、移転
- 本文の上に資料カードを重ねて参照
- Idea Boardへの資料配置

### 校正

- 右サイドバーの「校正」から、通常の11種類と手動文脈解析の2種類のルールで確認
- 試験機能としてSudachiによる形態素解析＋連語辞書、GiNZAによる係り受け解析＋主述の確認に対応。校正欄の「この原稿を解析」から実行します。開発用Python環境の導入方法と制限は [文脈解析の説明](docs/PROOFREAD_CONTEXT_ANALYSIS.md) を参照してください。
- 異字同訓の使い分け（答・応、熱・暑、乾・渇、直・治、習・倣）は近接する語から参考情報として提示。組ごとの無効化、会話文の除外、辞書での保護に対応し、自動置換は行いません。出典は文化審議会国語分科会『「異字同訓」の漢字の使い分け例』（2014年）。
- 各ルールは根拠にした資料を出典として表示。資料名・発行者・版・参照先と、その資料が述べている内容を添える
- 話し言葉の混入（ら抜き・い抜き・さ入れ）、漢字を開く、一文の長さと読点、重複表現・冗長表現、約物の使い方、表記のゆれ、語句の誤用、敬語の誤り、文体の混在、辞書の表記ゆれ
- 語句の誤用・敬語・約物は会話文の中も検査。その他のルールは会話文を対象から外すか選択可能
- 指摘をクリックすると本文の該当箇所を選択、置換候補があれば1クリックで適用
- ルールごとの有効・無効、一文の長さと読点の目安、会話文の扱いを設定として保存
- 「表記のゆれ」は検出項目ごとに切り替え可能。数字・英字の全角半角、全角と半角の間の空きは、書き方の流儀が分かれるため個別に外せます
- 無視した指摘はワークスペース（`.then/project.json`）にファイル単位で保存され、一覧から1件ずつ戻せます
- コードブロック、ルビの読み、URLは検査の対象外

出典に用いた資料:

- 文化審議会建議「公用文作成の考え方」（令和4年）
- 文化審議会答申「敬語の指針」（平成19年）
- 内閣訓令「公用文における漢字使用等について」、内閣告示「常用漢字表」「送り仮名の付け方」「外来語の表記」
- 文化庁「国語に関する世論調査」「ことば食堂へようこそ！」
- JTF日本語標準スタイルガイド（翻訳用）第3.0版（日本翻訳連盟、CC BY 4.0）
- 共同通信社『記者ハンドブック』、日本エディタースクール『日本語表記ルールブック』、JIS X 4051

慣用句の本来の意味・言い方は、文化庁の調査で取り上げられたものだけを収録しています。

#### 校正辞書

- 固有名詞・キャラクター名・作中の用語を登録し、校正の対象から外せます
- 一括入力欄に1行1語で貼り付けて登録。タブ・カンマ・2つ以上の空白で区切ると、表記／読み／種別／扱い／別表記まで指定できます
- 指摘カードの「辞書」からも登録できます。指摘された語が入った状態で開くので、名前がそれより長いときは書き足してから追加します
- 「守る」に指定した語には、どのルールも触れません。一文の長さや読点の数には従来どおり数えます
- 保存範囲はワークスペース（`.then/project.json`）と全ワークスペース共通の2種類。語ごとに保存範囲を移せます
- 一覧では、行を開いて表記・読み・種別・扱い・別表記・覚書を編集。種別での絞り込みと、表記順／更新順の並べ替えに対応
- 扱いを「揃える」にすると、登録した別表記の混入と、ルビの読みの食い違いを検出します。同じ読みに違う字が当たっている箇所は変換ミスとして表記を示します
- 「原稿から候補を出す」で、ルビの付いた語・敬称の直前の語・繰り返し出てくる片仮名語を候補として並べます。既定では走らず、押したときだけ動きます。選んだものだけが登録されます
- 一括入力欄への書き出しのほか、タブ区切りのテキストファイルへの保存と読み込みができます

### チェックポイント

- プロジェクト全体の手動保存点を作成
- 保存点と現在のプロジェクト、または保存点同士をファイル単位で比較
- プロジェクト全体または選択したファイル／フォルダだけを復元
- 競合時の上書き、別ファイルとして復元、スキップを選択
- 復元実行前に現在の状態を自動退避

### PDF / DOCXエクスポート

- 複数ファイルを任意の順序で束ねて出力
- PDFとWord（DOCX）に対応
- ページサイズ、余白、本文フォント、段組み、ヘッダー、ノンブルを設定
- 実際の出力エンジンを使ったプレビュー
- 生成進捗の表示

### Vivliostyleの利用とライセンス

### 表示と設定

- ライト／ダークを含む多数のカラーテーマ
- 濃色の操作盤と白い原稿面を組み合わせた「Workbench」、生成り紙調の「Index」、夜の書斎をイメージした「Night Library」
- 低彩度ブルーグレーの「Flat」、紙面調の「Newsroom」を含むライト／ダークテーマ
- 白をベースに黒をアクセントとした「Standard」テーマと、旧「Signal Red」から改名した「Red」テーマ
- Windowsにインストールされたフォントの利用
- 本文フォント、文字サイズ、行間、本文表示幅の調整
- 左右それぞれを、常時表示または画面端のホバー時だけ重ねる表示モード
- 左右サイドバーや各作業画面の状態を保存

## データの保存

- 原稿はワークスペース内の `.md` / `.txt` ファイルとして保存されます。
- ワークスペース固有の並び順、Idea、プロットなどは `.then/project.json` に保存されます。
- Idea Board、取り込んだ資料、資料の表示状態などもワークスペースの `.then` ディレクトリ以下で管理されます。
- アプリ設定、最近使ったワークスペース、開いていたタブなどはTauriのアプリデータディレクトリに保存されます。
- ブラウザ実行時はUI確認用として `localStorage` を使用します。

`.then` ディレクトリはThenが管理します。通常はファイルを直接編集せず、アプリ上から操作してください。

## インストール

[GitHub Releases](https://github.com/maybefix/Then/releases) から最新版をダウンロードできます。

- NSISインストーラー: `Then_*_x64-setup.exe`

v0.5.5以降はNSIS形式のみを配布します。

現在のWindowsインストーラーはコード署名されていないため、Windows SmartScreenが警告を表示する場合があります。

## 開発

### 必要なもの

- Node.js / npm
- Rust
- Tauri v2のWindows向け前提ツール

依存関係をインストールしてデスクトップアプリを起動します。

```powershell
npm install
npm run tauri:dev
```

ブラウザでUIだけを確認する場合:

```powershell
npm run dev:local
```

## ビルドと検証

```powershell
npm run build
npm run test:performance
npm run test:heading-move
npm run test:heading-dnd-ui
npm run test:export
npm run tauri:build
```

Windowsインストーラーは次の場所に生成されます。

```text
src-tauri/target/release/bundle/nsis/
```
