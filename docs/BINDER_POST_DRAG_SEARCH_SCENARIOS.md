# 投稿のドラッグと検索：場面ごとの比べ表

確認1の「決めてほしいこと」を、具体的な場面に当てはめて、案ごとに何が起きるかを並べた。
手順書は [BINDER_POST_DRAG_SEARCH_PLAN.md](BINDER_POST_DRAG_SEARCH_PLAN.md)。

- この表は、コードを読んで出した**見込み**。まだ動かしていない（縦書きで落とした位置と、落とす位置の印は特に分からない）。
- 決まった案は、そのままテストと実機確認の場面に使う（最後の節）。

## まず、言葉を3つだけ

| 言葉 | 意味 |
|---|---|
| 投稿 | 右のペイン「アイデア」の1件。ライブラリ全体で共有する |
| 本文 | 真ん中の書く画面（エディタ）。原稿のファイルの中身 |
| 下の段 | 投稿の行の、本文の下の段。左に時刻・作品名・札、右に操作のボタン（ポインタを乗せると出る） |

したいことは3つ。

1. **投稿を、本文へドラッグして入れる（U6）。** 今は落としても何も入らない。
2. **投稿を検索する（U9）。** 今は送って目で探すしかない。
3. **狭いペインで、ほかの作品の作品名が見えなくなるのを直す。**

---

## 場面の舞台

ライブラリ「本棚」を使う。

- 作品A・作品B がある。作品A を開いていて、本文は縦書きの「本文.md」。
  - 1行目「朝の港。」
  - 2行目「船が出る。」
- 投稿
  - P1「灯台の夢」と2行目「波の音が遠い」（作品A、受信箱）
  - P2「港で拾った言葉」（作品B、受信箱）
  - P3「夜の郵便局」（作品A、ノートにした。受信箱にない）
  - P4「続き：灯台守の話」（P1 への返信、受信箱から外した）
- アイデアのペインは「受信箱」を押してある。

記号: ✅ = できる・変わる　➖ = そのまま・できない　⚠️ = できるが、何かが見えなくなる・変わる　❓ = 工程9で確かめる

## まとめ：勧めの組み合わせで

| 場面 | 結果 |
|---|---|
| D1 本文へ落とす | ✅ 落とした位置に写しが入る（行が分かれる） |
| D2 すぐ打つ | ✅ 入れた文の後ろに続く |
| D3 Ctrl+Z | ✅ 入れた文だけが消える |
| D4・D5 ノートにした投稿・返信 | ✅ 写しが入る |
| D6 変換中 | ➖ 入らない |
| D7 落とす位置の印 | ❓ 工程9で確かめる |
| D8 投稿の側 | ➖ 受信箱に残る |
| D9・D10 ほかのドラッグ | ➖ 今のまま |
| S1・S2 検索 | ✅ 今の絞り込みの中で、本文に当たる投稿と返信先 |
| S3 作品名 | ➖ 当たらない |
| S4・S5 投稿した・直した | ✅ 見えなくならない |
| S6〜S8 | ✅ 元に戻る |
| N1〜N4 狭いペイン | ✅ 作品名と札が読め、押せる |
| K1 | ✅ 投稿は写し、ノート・資料は何も入らない（届くなら） |

- **原稿の文がなくなる場面はない。** U6 は文を足すだけで、Ctrl+Z 1回で足した分だけが消える。
- **投稿のファイルには何も書かない。** U6・U9・狭いペインのどれも、投稿を書き換えない。

## テストと実機確認への使い方

| 場面 | 自動テスト | 実機確認（一時ライブラリ） |
|---|---|---|
| D1〜D3・D6 | Edge で本物のエディタ（縦書き・横書き）に drop を送る | OS のドラッグで P1 の時刻から本文の「港」と「。」のあいだへ落とし、本文とファイルを読む。すぐ打つ・Ctrl+Z も OS のキー |
| D4・D5 | 同じ | ノートにした投稿・返信を落とす |
| D6 | 変換中の drop で入らない | OS の入力で IME を通せるかを先に確かめる。できなければそう書く |
| D7 | — | ドラッグの途中を撮る（Then の窓だけ） |
| D9・D10 | 本文の中の文のドラッグが今のまま | OS のドラッグ |
| S1〜S8 | jsdom: ペインの検索欄・並び・空にする・投稿・直す | OS の入力で検索欄に打つ（IME） |
| S1 の印 | — | 撮る（`CSS.highlights` は jsdom にない） |
| N1〜N4 | Edge で 300 px と 420 px の幅に描いて幅を測る（見込み） | ペインを狭くして撮り、作品名の幅を CDP で読む |
| K1 | 名前も付いた drop で写しが入る | 別ウィンドウを開いてから、窓を並べて OS のドラッグ |
| 全部 | ペインのほかの操作・U7・打鍵と IME のテストが今のまま | 再起動しても本文が残るか |
