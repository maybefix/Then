## 工程2: 仕組みの説明

### 言葉

| 言葉 | 意味 |
|---|---|
| 送る | ノート・画像・PDF を、別の作品（またはライブラリ直下）へ移動かコピーすること。以前の「…へ移動・コピー…」と同じ言い方 |
| 送り元・送り先 | 送る前にあった作品（直下）と、送った先 |
| 素材の段 | バインダーの三段（原稿／素材／投稿）の真ん中。素材フォルダの中身 |
| 資料のフォルダ | 取り込んだ資料の置き場所。作品は `<素材>/資料/`、直下は `資料/` |
| リンク索引 | 作品の中の `[[名前]]`・`@[[パス]]` の一覧。作品ごとに持つ |
| 行き先のないリンク | 指すファイルがないリンク。薄く描かれ、押しても開かない（3-2） |
| ボードのゴミ箱 | `.then/boards/.trash/`。Canvas で消したボードが入る |
| OS のゴミ箱 | Windows のごみ箱。Then のファイルの削除はここへ送る |

### 1. データの形

- **送る**: 保存の形は変えない。ファイルが別の作品のフォルダへ動き、両方の `project.json`（並び・進捗・スター）と、投稿の札（`posts.jsonl` の `note`）が書き換わる。
- **スター（案 A）**: 作品の `project.json` に `noteStars`（作品からの相対パス → 付けた時刻）を足す。進捗と同じく、改名・移動で付いていき、削除で外れる。古い Then はこの鍵を知らない。`ProjectConfig` は知らない鍵を読み飛ばし、保存のときに書かないので、**古い版で開いて `project.json` を保存するとスターが消える**（見込み。決めごと 3-1 の A を選ぶなら、ベータのため許すことになる）。
- **Q4・Q5**: 保存の形は変えない。
- **ボードのゴミ箱を空にする**: `.trash/` の中の `.canvas` を OS のゴミ箱へ送るだけ。

### 2. 利用者の操作と内部の処理（勧めの案で）

| 操作 | 内部の処理 |
|---|---|
| 素材のノート（または画像・PDF、選んだ複数）の右クリック →「移動・コピー…」 | 送り先（直下と、同じライブラリのほかの作品）・「コピー（元に残す）」「移動（元から取り除く）」を聞く。直していないものを保存し、Rust の新しい命令（`transfer_project_entries`、名前は案）が送り先の素材フォルダへ写す・移す。名前が重なれば「-2」。両方の `project.json` を書き換え、投稿の札を送り先へ付け替える。送り元で開いていたタブは閉じる。通知「「汐見」を作品Bへ移動しました」と「元に戻す」 |
| 通知の「元に戻す」 | 移動なら、送り先から元の場所へ戻す（送り先で直していなければ）。コピーなら、写しを OS のゴミ箱へ |
| ノートの右クリック →「スターを付ける」／「スターを外す」 | `project.json` の `noteStars` を書く。素材の段の行に星の印 |
| 素材の段の見出しの星のボタン | スターの付いたノートだけを出す（もう一度押すと全部）。ほかのノートの入ったフォルダは、中にスターがあれば出す |
| 画像・PDF を Ctrl+クリック | ファイルの行と同じ選択に足す・外す |
| 選んだもの（ノートと画像・PDF）を素材の中のフォルダへドラッグ | `move_project_entries` が画像・PDF も受け付け、まとめて動かす。失敗したら全部戻す |
