## 0. 準備（本番のデータを守る）

開発版（`tauri dev`）と普段使っている Then は識別子が同じ `local.then` なので、アプリの状態やプロフィールのテンプレートを共有する。原稿にも書き込むので、本番のライブラリでは試さない。

1. Then を終了し、`C:\Users\uest\AppData\Roaming\local.then` をフォルダごと別の場所へコピーしておく（確認後に戻せるように）。
2. 本番とは別の場所に、確認用のライブラリと作品を Then で作る（例：`Documents\Then確認用\QAライブラリ\作品A`、もう1つ `作品B`）。
3. 確認用の原稿を作る：

   ```bash
   node scripts/create-frontmatter-qa-files.mjs "C:\Users\uest\Documents\Then確認用\QAライブラリ\作品A"
   ```

4. 開発版を起動：`npm run tauri:dev`。開いたら確認用ライブラリの作品Aを開く（本番のライブラリは開かない）。
5. 終わったら開発版を閉じ、手順1のコピーで `local.then` を戻す。

## 2. プロパティ欄（FM-08・09・10・14・16・19・22・23・24）

右サイドバーの切り替えで「プロパティ」を選ぶ。横書き・縦書き・ページ表示のそれぞれで同じ欄が出ること（FM-14・18）。

- [ ] `07_記事`：5行が型のアイコン・名前・値で並ぶ。件数が「5件」（以前は空でない行を数えて7件だった）。
- [ ] チェックボックス、日付、数値、テキスト、リスト（Enterで追加・×で削除）を変えて保存：変えた行だけがファイルで変わる。
- [ ] テキストを日本語入力で変換中にEnter：変換が確定するだけで、値は書き込まれない。
- [ ] 型アイコンから値を失う型（テキスト→数値など）を選ぶ：「値を消して…にする」「…のままにする」が出る。

- [ ] 「＋」：名前の入力欄が出て、以前選んだ型の名前が候補に出る。重複する名前では追加できない。

- [ ] `05_不正なYAML`：見出しに「エラー」が出て、フォームは出ず「ソースで修正」になる。
- [ ] プロパティ欄で Escape：本文の元のキャレット位置に戻り、画面がスクロールしない（縦書き・タイプライター有効でも）。
- [ ] プロパティを2回変えて、欄にフォーカスがある状態で Ctrl+Z を2回 → Ctrl+Shift+Z と Ctrl+Y：1手ずつ戻り・やり直せる。本文の Ctrl+Z の履歴には影響しない。
