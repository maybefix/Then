## まず、言葉を3つだけ

| 言葉 | 意味 |
|---|---|
| コピーのカード | 昔、Idea の「Canvas へ送る」で作ったテキストのカード。文は Idea からの写し |
| 元の印 | コピーのカードに付いている「どの断片から来たか」のメモ（`thenOrigin`）。画面には出ない |
| ノートのカード | ノートのファイルを指すカード（4-2）。ノートの本文を全部映す。カードで直すとノートに書かれる |

移行でしたいことは1つだけ。**コピーのカードを、元が今あるノートを指す「ノートのカード」に差し替える。**

## 場面の舞台

どの場面も、作品A を使う（自動テストの見本と同じ）。

**移行の前の Idea**

- スレッド「場面: 港」に断片が3つ
  - 「港の場面の一」
  - 「港の場面の二」
  - 「Canvasから来た断片」
- 受信箱に断片が2つ
  - 「灯台の夢」
  - 「使用済みの断片」（本文に入れた印つき）

**2-4・2-5 の移行のあと**

- スレッドはノート `素材/場面： 港.md` になった。中身はこう。

  ```
  # 場面: 港

  港の場面の一

  港の場面の二

  Canvasから来た断片
  ```

- 受信箱の断片は、それぞれ投稿1件になった。
- Canvas に「投稿を指すカード」はない。

## 決めごと1：文が元と違うカード（S1・S2）

**S1**　カード「港の場面の一」。元の断片も「港の場面の一」。
**S2**　カード「港の場面の一（波止場で）」。カードで書き足した。

| 案 | S1 | S2 |
|---|---|---|
| **A（勧め）** 同じときだけ | ✅ ノート「場面： 港」のカードになる | ➖ テキストのまま。書き足した文も残る |
| B 違っても置き換え、文をノートに足す | ✅ 同上 | ⚠️ ノートのカードになる。ノートの末尾に「港の場面の一（波止場で）」の段落が増える |
| C 違っても置き換え、文はバックアップだけ | ✅ 同上 | ⚠️ ノートのカードになる。書き足した文は画面から消える（バックアップにはある） |

**どの案でも S1 で起きること:** カードに映る文が「港の場面の一」の1行から、ノートの全文（4段落）に変わる。

**比べどころ:** S2 で、利用者の書いた文が画面に残るのは A と B だけ。B はノートの中身が変わる。

## 決めごと2：元が見つからないカード（S3）

**S3**　カード「消した断片」。移行の前に、Idea で元を消していた。

| 案 | S3 のカード | ボードのファイル |
|---|---|---|
| **A（勧め）** そのまま、元の印も残す | ➖ テキストのまま | 書かない |
| B そのまま、元の印を外す | ➖ テキストのまま | 書く（バックアップも作る） |
| C 消す | ⚠️ カードがなくなる | 書く |

**比べどころ:** 見た目は A も B も同じ。違いは、A は作品を開くたびに調べ直す（読むだけ）、B は1回で済むがファイルを書く。C だけ文がなくなる。

## 決めごと3：元が投稿のカード（S4・S5）

**S4**　カード「灯台の夢」。元は投稿のまま。
**S5**　カード「灯台の夢」。その投稿を、あとで「ノートにする」でノート `素材/灯台の夢.md` にした。

| 案 | S4 | S5 |
|---|---|---|
| **A（勧め）** ノートにした投稿だけ置き換え | ➖ テキストのまま | ✅ ノート「灯台の夢」のカードになる |
| B 投稿は全部そのまま | ➖ テキストのまま | ➖ テキストのまま |
| C 移行で投稿をノートにしてから置き換え | ⚠️ ノート「灯台の夢」が新しくでき、カードはそのノートのカードになる。投稿は受信箱から外れる | ✅ A と同じ |

**手元の Books では:** カード2枚とも S4 に当たる（元は「使用済みの断片」と同じく、本文に入れた印つきの断片）。

- A・B なら、何も変わらない。
- C なら、ノートが1本増え、カード2枚がそのノートのカードになる。ただし2枚のうち1枚はライブラリ直下のボードにあるので、S8 と同じ理由でそのまま。

## 決めごと4：同じスレッドから来たカードが何枚もある（S6）

**S6**　枠「場面: 港」の中に、カード「港の場面の一」→「港の場面の二」（矢印でつながる）。

| 案 | 枠 | カード2枚 | 矢印 |
|---|---|---|---|
| **A（勧め）** 2枚以上なら全部そのまま | ➖ | ➖ テキストのまま | ➖ |
| B 全部置き換える | ➖ | ⚠️ 2枚とも同じノートのカードになり、同じ全文が2つ並ぶ | ⚠️ 残るが「一 → 二」の意味がなくなる |
| C 枠ごと1枚にまとめる | ⚠️ ノートのカード1枚に変わる | ⚠️ なくなる | ⚠️ なくなる |

**比べどころ:** 置き換えて読みやすくなる案はない。B は重複、C は位置と矢印を失う。

## 決めごと5：カードの ID・位置・色・矢印（S1・S7）

**S1**　カードは黄色、右のカードへ矢印が1本。
**S7**　S1 のカードの下に、子のカード「港の補足」がぶら下がっている（スレッド）。

| 案 | S1 | S7 の子のカード |
|---|---|---|
| **A（勧め）** 保つ | ✅ 同じ場所・同じ大きさ・黄色のまま。矢印も残る | ➖ その場に残り、スレッドからは外れる（ノートのカードはスレッドに入れないため。4-4 と同じ） |
| B 横に新しく足す | ⚠️ 元のテキストカードも残る。ノートのカードは横に新しく置かれ、矢印はない | ➖ スレッドのまま |

**比べどころ:** B は置き換えではなく「足す」なので、カードが増えるだけになる。

## 置き換えない場面（S8・S11）

| 場面 | どうなるか | 理由 |
|---|---|---|
| S8 ライブラリ直下のボード | ➖ どの案でもそのまま | ライブラリ直下のボードは、作品の中のノートを指せない |
| S11 ドラッグで作ったコピー | ➖ どの案でもそのまま（9-2 が A のとき） | 元の印がないので、元を確かめられない |

9-2 を B（文が同じ断片を探す）にすると、S11 も S1 と同じように置き換わる。ただし、たまたま同じ文の別のカードも置き換えるおそれがある。

## 決めごと7：別ウィンドウで同じボードを開いている（S9）

起きるのは、別ウィンドウで作品A のボードを開いたまま、メインの画面で作品A を開き直したときだけ。起動のときは別ウィンドウがない。

| 案 | 起きること |
|---|---|
| **A（勧め）** 書き切ってから移し、読み直してもらう | 別ウィンドウのカードが、その場でノートのカードに変わる。別ウィンドウで直したばかりの文も、先に保存されてから移る |
| B 何もしない | 別ウィンドウは古いまま。次に保存すると「ほかのアプリでファイルが変更されました」が出る。「この内容で上書きする」を押すと置き換えが戻る（次に開いたとき、また置き換わる） |

## 決めごと8：ゴミ箱のボード（S10）

| 案 | ゴミ箱にある間 | ボードを戻したとき |
|---|---|---|
| **A（勧め）** 移さない | ➖ テキストのまま | 次に作品を開いたときに置き換わる |
| B 移す | ✅ ゴミ箱の中で置き換わる | 置き換わった形で戻る |

**比べどころ:** 戻したあとの見た目は同じ。違うのは、置き換わるのが「戻した次の開き直し」か「すぐ」か。

## まとめ：勧めの組み合わせ（全部 A）で

| 場面 | 結果 |
|---|---|
| S1 そのままの文 | ✅ ノートのカード（同じ場所・色・矢印）。映る文はノート全文に増える |
| S2 直した文 | ➖ テキストのまま |
| S3 元なし | ➖ テキストのまま |
| S4 投稿のまま | ➖ テキストのまま |
| S5 ノートにした投稿 | ✅ そのノートのカード |
| S6 同じスレッドから2枚 | ➖ テキストのまま |
| S7 スレッドの親 | ✅ 置き換わり、子はスレッドから外れてその場に残る |
| S8 ライブラリ直下 | ➖ テキストのまま |
| S9 別ウィンドウ | ✅ その場で置き換わる |
| S10 ゴミ箱 | ➖ 戻したあとで置き換わる |
| S11 ドラッグのコピー | ➖ テキストのまま |

- **文がなくなる場面はない。** 置き換わるのは、文が元とまったく同じカードだけ。
- **置き換えたカードは、移行の前の形でバックアップに残る**（`.then/backups/copy-cards-<日時>/`）。
- **手元の Books では、何も変わらない**（2枚とも S4）。通知も出ない。

## テストと実機確認への使い方

決まった案で、各場面を次のように確かめる。

| 場面 | Rust の自動テスト | 実機確認 |

| S1・S5・S7 | 置き換わる・ID と位置と色と矢印が同じ・子の扱い | ボードを開いて見る。ノートのカードで直してノートに書かれるか |
