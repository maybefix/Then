### 気づいた点

1. **アプリのほかの所での呼び名。** Canvas を開くボタン（App.tsx 11924行）の名前は「Idea Board を開く」、ショートカットは Ctrl+Alt+B。画面のモードの名前は「キャンバス」。プラグインの画面は「0個を導入済み」。作品を切り替えるパンくずのメニューでは、今の作品は「最近開いたプロジェクト」に印つきで出て、押しても何もしない。
2. **パレットの絞り込みは、名前と補助の文字の両方で引く**（`CommandPalette.tsx` の `matchesQuery`）。補助の文字を変えると、引ける言葉も変わる。
3. **表の区切りの読み方。** 区切りの行の `---`（揃えなし）と `:---`（開始揃え）は、どちらも「開始揃え」として読む（`markdownTableRows` の `alignments`）。今の `tableAlignmentEdit` は区切りの行を全部の列について作り直すので、揃えのない列も `:---` で書き出し、空白の入れ方も `| :--- | :---: |` に揃えてしまう。
4. **テストの期待。** `test:markdown-tables` は列の揃えの結果を読み直して確かめるだけで、区切りの行の文字そのものは見ていない。今の書き方のままで通る見込み。`test:palette-commands` は今の一覧をそのまま期待にしているので、直した所の期待を書き換える。
5. **「前」の一式。** main `9cfcef6` のコードは、PR #18 の「後」の一式を動かした `ce748f3` と同じ（その後に変わったのは手順書だけ。`git diff --stat` で確かめた）。その結果を今回の「前」に使う。70本のうち、元から失敗している4本（`test:ai-selection`、`test:canvas-save`、`test:v058-bundle`、`test:v0511-themes`）のほかは通った。

## 工程5: 案

### 決めてほしいこと

1. **同じ処理の項目が2つ**
   - (a) 「Project Canvas を開く」を外し、「Idea Board を開く」（Ctrl+Alt+B）を残す。アプリのボタンとショートカットと同じ名前のほうを残す。
   - (b) 2つとも残す。
   - 勧め: (a)。
2. **本文がないとき**
   - (a) 本文を使う項目は、本文がなければ全部「本文を開いてください」で使えなくする（太字・見出し・文章方向・記法をクリアも。圏点・ルビ・縦中横・列の揃えも、本文がないときはこちらを先に出す）。「原稿を整える…」の「エディタを開いてください」も揃える。
   - (b) 「エディタを開いてください」を「本文を開いてください」に揃えるだけにする。
   - 勧め: (a)。選んでも何も起きない項目がなくなる。
3. **補助の文字の英語**
   - (a) 日本語にする。作品を開く項目は「プロジェクト」、チェックポイントは「チェックポイント」、Canvas は「キャンバス」、プラグインは「N個を導入済み」（プラグインの画面と同じ）。絞り込みは日本語で引けるようになり、英語（workspace など）では引けなくなる。
   - (b) ショートカットや記法ではない補助の文字は消す。
   - 勧め: (a)。ほかの項目の補助の文字（「行数・列数を指定」など）と揃う。
4. **今の作品も「開く」に出る**
   - (a) 一覧から外す。パンくずのメニューでも、今の作品は押しても何もしない。
   - (b) 残して使えなくする（使えない理由を出す）。
   - 勧め: (a)。
5. **表の列の揃え**
   - (a) 選んだ列の区切りの文字だけを書き換え、ほかの列と空白はそのまま残す。
   - (b) 今と同じく行全体を書き直すが、揃えのない列は `---` のまま書く。
   - 勧め: (a)。利用者が書いた区切りの行を、選んだ所のほかは変えない。
