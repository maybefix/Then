# v0.7.0 原稿用紙モード 実機確認

自動テストでは確かめられない項目を、実機（Windows・Tauri版）で確認するための手順です。

## 準備

1. 起動中の Then を終了する（Then は同時に1つしか起動できません）。
2. `src-tauri\target\release\bundle\nsis\Then_0.7.0_x64-setup.exe` を実行して上書きインストールする。
   - 元に戻すときは、同じフォルダの `Then_0.6.7_x64-setup.exe` を実行します。設定は 0.6.7 でもそのまま読めます（原稿用紙の設定だけが無視されます）。
3. 確認用の原稿は `test-artifacts\manuscript-device-qa\` にあります。
   - `01_字詰め確認.md`：字詰め・禁則・ルビ・欧文の見本
   - `02_長文10万字.md`：入力の重さを見るための約10万字の原稿
4. 設定 →「本文」→「原稿用紙」を「使用する」にする（20字×20行、罫線・ページ境界ON）。

## 1. IME（いちばん確かめたい項目）

`01_字詰め確認.md` の任意の行で、Windows の IME を使って入力する。

- [ ] 変換候補ウィンドウが、入力している位置のすぐ横に出る
- [ ] 変換中にスペースで候補を切り替えても、候補ウィンドウが別の場所へ飛ばない
- [ ] 行末（20字目付近）で変換して、行が送られても候補ウィンドウが入力位置についてくる
- [ ] 確定した文字だけが本文に入る（変換途中の文字が残らない）
- [ ] 縦書き・横書きの両方で同じ
- [ ] 連続表示・ページ表示の両方で同じ

## 2. 入力の重さ

`02_長文10万字.md` を開き、原稿の真ん中あたりで日本語を続けて入力する。

- [ ] 原稿用紙OFFと比べて、打鍵から文字が出るまでの遅れが気にならない
- [ ] タイプライタースクロールが、改行のたびにひっかからずに動く
- [ ] Backspace の長押しで、表示が詰まらない

気になる場合は、原稿用紙OFF・行番号ONなど、どの組み合わせで重いかをメモしてください。

## 3. 見た目と枚数

- [ ] 罫線の升目に1字ずつ収まっている（ずれが溜まっていかない）
- [ ] 20字ちょうどの行は1行、21字の行は2行になる
- [ ] 句読点・閉じ括弧が行頭に来ない
- [ ] ルビが升目の脇に出て、親文字が升目からずれない
- [ ] ステータスバーの「原稿用紙 ○.○枚」が、開いた直後に一度出たあと、スクロールしたりカーソルを動かしたりしても変わらない
- [ ] 連続表示で、20行ごとに「nページ終了 / n+1ページ開始」の線が出る
- [ ] ページ表示で、1ページが20字×20行になる。先頭・中央・末尾のどこを開いても総ページ数が変わらない
- [ ] 設定で 40字×30行 などに変えると、すぐに組み直される
- [ ] 原稿用紙を「使用しない」に戻すと元の表示に戻り、ファイルの中身は変わっていない

## 4. Zoneモード（サイドペインのホバー表示）

設定 →「外観」→「サイドペインの表示」を「左右ともホバー表示」にする。

- [ ] 画面の右端へポインターを移すと右ペインが出て、離すと隠れる
- [ ] 右ペインの中をクリックして操作している間は隠れない
- [ ] プラグインのビューを右ペインに出している場合も、同じように出入りする

## 結果の伝え方

課題表（原稿用紙モード課題表）の MS-05（IME）と MS-13（入力の重さ）に書き込むか、気になった項目と再現手順をそのまま伝えてください。
