# Then 操作マニュアル

Thenは、小説やシナリオなどの日本語原稿を縦書きで執筆するためのWindowsデスクトップエディタです。

> 対象バージョン: 0.6.6
> 動作環境: Windows x64（Tauriデスクトップアプリ）
> ブラウザ版はUI確認用であり、一部のファイル操作は利用できません。

## Thenとは

Thenは、Markdownまたはテキストファイルを原稿として直接扱う執筆環境です。

- 縦書き／横書き本文エディタ
- タイプライタースクロール
- フォルダ単位の原稿管理
- Idea、Plot、資料、Idea Boardによる構想整理
- プロジェクト全体のチェックポイントと復元
- 複数ファイルを束ねたPDF／DOCX出力

原稿は一般的な `.md` / `.txt` ファイルとして保存されます。Then独自の形式に変換しなくても、ほかのエディタから同じ原稿を開けます。

## インストールと起動

公式の[GitHub Releases](https://github.com/maybefix/Then/releases)から、NSISインストーラー `Then_*_x64-setup.exe` をダウンロードして実行します。v0.5.5以降のWindows向け配布はNSIS形式のみです。

現在のインストーラーはコード署名されていないため、Windows SmartScreenが警告を表示する場合があります。配布元が `https://github.com/maybefix/Then` であることを確認してください。

### 起動ポータル

起動すると「執筆するワークスペースを選んでください。」という起動ポータルが表示されます。

- **フォルダを開く**: 執筆に使うフォルダをワークスペースとして開きます。
- **最近のワークスペース**: 最近開いたフォルダを選んで再開します。
- **履歴を消去**: 最近のワークスペース一覧を消去します。原稿ファイルは削除されません。
- **次回から前回のワークスペースを直接開く**: 次回起動時にポータルを省略します。
- **設定**: ワークスペースを開く前に表示や起動方法を変更できます。

前回のワークスペースが移動・削除されている場合は警告が表示されます。別のフォルダを選び直してください。

## 画面構成

ワークスペースを開くと、画面は次の領域に分かれます。

| 領域 | 役割 |
| --- | --- |
| トップバー | ファイルメニュー、パンくず、画面モード、縦横切替、テーマ、設定。 |
| アクティビティバー | ファイル表示、プロジェクト検索、開いているカード、新規ファイル、新規フォルダ。 |
| 左サイドバー | ファイルツリー、見出しアウトライン、検索・置換、開いているカード。 |
| タブ列 | 開いている原稿を切り替えます。 |
| 本文エディタ | 原稿を縦書きまたは横書きで編集します。 |
| 右サイドバー | IdeaとPlot。幅の拡張と折りたたみができます。 |
| ステータスバー | 保存状態、文字数、設定に応じてファイルパスを表示します。 |

トップバー中央のモード切替から、次の作業画面を開けます。

- **本文**: 通常の執筆画面
- **キャンバス**: Idea Board
- **エクスポート**: PDF／DOCX出力
- **履歴アイコン**: チェックポイント
- **プラグインのアイコン**: 導入したプラグインが追加する作業画面

キャンバスとエクスポートは、設定により別ウィンドウで開くこともできます。

## ワークスペースとデータ保存

### ワークスペース

「フォルダを開く」で選択したフォルダが1つのワークスペースになります。配下のサブフォルダと `.md` / `.txt` ファイルをThenから管理できます。

サブフォルダを独立したワークスペースとして開くと、そのフォルダ自身に専用のThen管理データが作られ、IdeaやPlotなども別管理になります。

### 保存場所

- 原稿: ワークスペース内の `.md` / `.txt`
- 並び順、Idea、Plot、ファイルの進捗ラベルなど: ワークスペース内の `.then/project.json`
- チェックポイントと復元前の退避: ワークスペース内の `.then/checkpoints/`
- Idea Board: ワークスペース内の `.then/boards`
- 取り込んだプロジェクト資料: ワークスペース内の `.then/references`
- 資料カードの配置: ワークスペース内の `.then/reference-layouts`
- アプリ設定、最近のワークスペース、開いていたタブなど: Tauriのアプリデータフォルダ

`.then` はThenが管理するディレクトリです。通常はファイルを直接編集せず、アプリから操作してください。

### 自動保存

本文は編集後に自動保存されます。ファイルメニューから手動保存することもできます。ステータスバーには「保存済み」「編集中」「保存中」「エラー」などの状態が表示されます。

### 別の端末で同じワークスペースを開く

ワークスペースのフォルダ全体を移動・コピーするか、クラウドストレージの同期フォルダに置けば、原稿とプロジェクト固有の進捗ラベル、チェックポイントを別の端末でも利用できます。Then独自のクラウド同期機能や、複数端末での同時編集機能ではありません。

1. 端末Aで未保存のタブがなく、本文が「保存済み」になったことを確認し、Thenを終了します。
2. ワークスペースのフォルダ全体を同期またはコピーします。隠しフォルダとして扱われることがある `.then` も含め、同期除外に設定しないでください。
3. クラウドストレージを使う場合は、端末Aのアップロードと端末Bのダウンロードが両方完了したことを確認します。オンデマンドファイルは端末Bへ取得しておきます。
4. 端末BのThenで、同期・コピーされたフォルダを「フォルダを開く」から選びます。以前と違う絶対パスでもかまいません。
5. 作業後は端末BのThenを終了し、同期完了を確認してから端末Aへ戻ります。

最近開いたワークスペース、タブ、カーソル位置、テーマ、ウィンドウ位置、インストール済みプラグインなどは端末ごとの設定で、フォルダと一緒には移りません。別端末で初めて開く際はフォルダを選び直してください。

同期が途中の状態で開くと、進捗やチェックポイントが一時的に読み取れないことがあります。読み取り専用・未取得・同期競合の通知が出た場合は、まず同期とファイル取得の完了を確認し、Thenのウィンドウを再度アクティブにするか、チェックポイント画面を開いて再読込してください。競合コピーができた場合、Thenは自動で統合しません。両端末のデータを別途保全し、内容を確認してから解消してください。

チェックポイントは原稿テキストと並び順を記録する保存点であり、画像・PDF・プラグインデータなどを含むワークスペース全体のバックアップではありません。定期的にワークスペースのフォルダ全体を別の場所へバックアップしてください。

## ファイルとフォルダ

### ファイルメニュー

トップバー左のメニューボタンから、主に次の操作を行えます。

| 操作 | 内容 |
| --- | --- |
| 新規ファイル | 一時的な新規原稿タブを作ります。 |
| ファイルを開く | 単一の `.md` / `.txt` を開きます。 |
| 保存 | 現在の原稿を保存します。 |
| 別名で保存 | 保存先とファイル名を指定します。 |
| フォルダを開く | ワークスペースを切り替えます。 |

### ワークスペース内の操作

ファイルツリー、パンくず、項目メニューから次の操作ができます。

- ファイル／フォルダの新規作成
- 名前変更
- 別フォルダへの移動
- 同一フォルダ内の並び替え
- `Ctrl`を押しながら複数ファイルを選択し、ドラッグでまとめて並び替え／フォルダ移動
- ファイルの追加
- 削除

削除した項目は即座に完全消去せず、ワークスペース内のThen管理用Trashへ移動します。フォルダを削除する場合は、配下に含まれるファイル数などが確認画面に表示されます。

### パンくず

トップバーのパンくずには、ワークスペースから現在のファイルまでの階層が表示されます。各階層を選ぶと、そのフォルダの内容と操作メニューを開けます。

## タブ

- タブはパンくずの下に横並びで表示されます。
- 複数の原稿を同時に開けます。
- すでに開いているファイルを選ぶと、既存タブへ切り替わります。
- タブを切り替えて戻ったときは、そのタブで見ていた本文位置とカーソル位置を復元します。
- 未保存の変更があるタブは保存状態で区別されます。
- タブの閉じるボタンで文書を閉じ、右端の「＋」で新しいタブを作成できます。
- タブを中クリックしても閉じられます。タブバーの空いている所をダブルクリックすると新しいタブを作成します。新しいタブは選択中のタブのすぐ右に開きます。
- タブはドラッグして並べ替えられます。ドラッグ中に Esc を押すと取り消せます。キーボードでは、タブにフォーカスがある状態で Ctrl+Shift+← / → を押すと移動します。
- タブが横にはみ出したときは、タブバー上でマウスホイールを回すと横にスクロールします。選択中のタブは常に見える位置へ寄せられます。
- タブを右クリックすると、「閉じる」「他のタブを閉じる」「右側のタブを閉じる」「保存済みのタブを閉じる」「閉じたタブを開き直す」「パスをコピー」「フォルダーで表示」を選べます。複数のタブを閉じるときは、未保存の変更があるタブについてまとめて一度だけ確認します。
- キーボード操作: Ctrl+W で現在のタブを閉じ、Ctrl+Tab / Ctrl+Shift+Tab（または Ctrl+PageDown / Ctrl+PageUp）で次／前のタブへ切り替えます。Ctrl+Shift+T で直前に閉じたタブを元の位置に開き直します（現在のプロジェクトで閉じた、保存先のあるファイルが対象。最大10件）。
- 設定の「ファイル」にある「タブを表示」で、タブバーの表示／非表示を切り替えられます。
- 同じく「タブバーの表示方法」で「上端にカーソルを寄せたときだけ表示」を選ぶと、タブバーは普段隠れ、パンくずのすぐ下にカーソルを寄せたときだけ本文へ重ねて表示されます。ノートパソコンなど画面の縦幅が限られる環境で、編集面を広く保てます。
- 開いているタブ、並び順、選択中のタブ、本文位置はプロジェクトごとに記憶されます。別のプロジェクトへ切り替えても、戻ったときに以前のタブ構成が復元されます。
- プロジェクト切替後は、切替前のプロジェクトのタブを記憶したことが画面下部に通知されます。
- Then内でファイルやフォルダを移動・改名した場合、開いているタブも新しいパスへ追従します。アプリ外で移動・改名された場合も、ファイルIDまたは内容が一意に一致すれば復元時に追従します。
- 復元対象のファイルが削除済み、または移動先を安全に特定できない場合、そのタブだけを除外して件数を通知します。他のタブはそのまま復元されます。
- 新規タブには、ファイル作成やワークスペースを開くための案内が表示されます。

## 本文を執筆する

### 縦書きと横書き

既定は縦書きです。トップバーの縦横切替ボタン、または設定の「本文方向」から横書きへ切り替えられます。

### タイプライタースクロール

入力中の行を画面内の一定位置に保つ機能です。

- 設定の「本文」タブでオン／オフを変更できます。
- 「固定位置」で入力行を置く位置を調整できます。
- 「タイプライター中央線を表示」をオフにすると、固定位置を示す線だけを非表示にできます。
- マウスホイール、クリック、キー入力などの操作を始めると、初期位置調整は中止されます。

### 本文表示幅

設定の「文字表示幅」で、編集領域に対して本文を表示する幅を調整できます。縦書きでは縦方向、横書きでは横方向の表示範囲に反映されます。

### 文字数

ステータスバーに現在の原稿の文字数が表示されます。「文字数に空白を含める」「文字数にコードを含める」で数え方を変更できます。

## 文字装飾と縦書き記法

選択範囲に対して、ショートカット、右クリックメニュー、コマンドパレットから記法を適用できます。

| 装飾 | 記法 | 操作 |
| --- | --- | --- |
| 太字 | `**本文**` | `Ctrl+B`。同じ操作で解除。 |
| 圏点 | `[本文(em,goma)]` | `Ctrl+I`。同じ操作で解除。 |
| ルビ | `[本文(rb,ルビ)]` | 読みをダイアログで入力。 |
| 縦中横 | `[本文(tcy)]` | 数字などを横並びで表示。 |
| 行揃え | `[(al:start|center|end)]` | 行頭、中央、行末を選択。 |
| 見出し | `#`〜`######` | `Ctrl+1`〜`Ctrl+6`。 |
| 見出し解除 | なし | `Ctrl+0`。 |

青空文庫形式の `｜本文《ルビ》`、漢字直後の `《ルビ》`、`《《圏点》》` も認識します。

ルビ、圏点、縦中横は、改行をまたがない選択範囲に適用してください。「記法をクリア」を使うと、選択範囲または行から独自記法を外せます。

### コードブロックと行内コード

技術的な内容を書くときは、コードを本文と区別できます。

- `` ``` `` または `~~~`（3個以上）の行で囲んだ範囲がコードブロックです。閉じる行は、開く行と同じ記号を同じ数以上並べます。閉じる行がない場合はコードブロックになりません。
- `` `…` `` で囲んだ範囲は行内コードです。
- コードの中では、見出し・ルビ・太字などの記法やコメントを解釈せず、書いたとおりに扱います。
- コードは本文と同じ組方向（縦書きなら縦書き）で、等幅フォントと背景色で表示されます。長い行は折り返します。
- コードブロック内で `Tab` を押すと半角スペース4個を入れ、`Shift+Tab` で行頭の空白を最大4個取り除きます。複数行を選択しているときは各行に適用します。
- PDF・DOCXでは、コードも本文と同じ組方向で出力されます（``` の行は出力しません）。Web小説用テキストでは書いたとおりに出力します。
- 「文字数にコードを含める」をオフにすると、コードブロックと行内コードを文字数から除きます。

### 画像

`![説明](画像の場所)` と書くと画像を入れられます。

- 画像の場所は、原稿ファイルからの相対パス（例：`img/挿絵.png`）か、`https://` で始まるWebの画像のURLです。ローカルの画像は作品フォルダの中にあるものだけ表示・出力します。
- 本文では記法を書いたとおりに表示し、記法にマウスを重ねると画像を浮かべて表示します。
- 1行に画像だけを書くと、PDFでは独立した図版として版面に収まる大きさで中央に配置します。行頭に `[(al:start)]`・`[(al:end)]` を付けると、天付き・地付き（横書きでは左寄せ・右寄せ）にできます。文の途中に書いた画像は1文字分の高さで行内に置きます。
- 図版の「説明」はキャプションとして画像の下（縦書きでは左）に印字します。書き出し画面の「本文設定」→「図版の説明をキャプションとして印字」で切り替えられます。説明が空の図版にはキャプションを付けません。
- Webの画像は保存せず、表示・出力のたびに読み込みます。読み込めない画像は、PDFでは代わりに `［説明］` を印字し、書き出し画面に件数を表示します。
- DOCXでは現在、画像の代わりに `［説明］` を出力します。Web小説用テキストでは書いたとおりに出力します。

### コメント

原稿に残したいメモや没にした文は、コメントにしておけます。コメントは文字数、アウトライン、校正、エクスポート（PDF・DOCX・投稿用テキスト）のいずれにも含まれません。

- 行頭（字下げの空白の後でも可）が `//` で始まる行は、その行全体がコメントです。行の途中の `//` や全角の `／／` はコメントになりません。
- `<!--` で始まり `-->` で終わる行もコメントです。複数行にまたがる場合は、`<!--` で始まる行から `-->` で終わる行までがコメントになります。`-->` がない場合はコメントになりません。
- `Ctrl+/` で、カーソルのある行（または選択範囲の行）を `//` コメントにします。もう一度押すと元に戻ります。`<!-- -->` の行では囲みを外します。
- コードブロックの中では `Ctrl+/` は使えません（コードの `//` はコードの一部です）。``` の行を含めてブロック全体を選ぶと、ブロックごとコメントにできます。
- 本文として行頭に `//` を書きたいときは `\//` と書きます。エクスポートでは `//` として出力されます。
- `Ctrl+Shift+/` または設定の「コメントを表示」で、コメントの表示と非表示を切り替えます。非表示でも、カーソルがあるコメントは表示されます。
- コメント行には行番号が付かないため、表示を切り替えても本文の行番号は変わりません。

## コマンドパレットとショートカット

`Ctrl+P` でコマンドパレットを開きます。コマンド名を入力して絞り込み、`↑` `↓` で選択、`Enter` で実行、`Esc` で閉じます。

| ショートカット | 操作 |
| --- | --- |
| `Ctrl+P` | コマンドパレット |
| `Ctrl+Alt+I` | Ideaへメモを追加 |
| `Ctrl+B` | 太字 |
| `Ctrl+I` | 圏点 |
| `Ctrl+1`〜`Ctrl+6` | 見出し1〜6 |
| `Ctrl+0` | 見出し解除 |
| `Ctrl+/` | 行をコメントにする／戻す |
| `Ctrl+Shift+/` | コメントの表示・非表示 |
| `Tab` / `Shift+Tab` | コードブロック内でインデント／インデント解除 |

## 左サイドバー

### アクティビティバー

- **ファイルツリー**: ファイルと見出しを表示します。
- **プロジェクト検索**: 検索・置換画面を表示します。
- **新規ファイル**: 原稿を追加します。
- **新規フォルダ**: 選択中の場所へフォルダを追加します。

### ファイル表示

ファイルツリーはフォルダ階層をコンパクトに表示します。各ファイルの右端の記号（未・執・推・完・ア）を押すと進捗を変えられます。

- **絞り込み**: 左サイドバー見出しの「ファイル」を押すと、未着手・執筆中・推敲中・完了・アーカイブのいずれかのファイルだけを表示できます。該当ファイルを含むフォルダだけが残ります。
- **アーカイブ**: 進捗を「アーカイブ」にしたファイルは、通常のツリーに表示されません。見るときは絞り込みで「アーカイブ」を選びます。ライブラリ画面の進捗バーには数えませんが、ファイル数と字数には含めます。

### 見出しアウトライン

- 現在の原稿またはプロジェクト内の見出しを階層表示します。
- 見出しを選ぶと本文の位置へ移動します。
- 現在カーソルがある見出しはアクセント色で強調表示されます。
- 通常クリックした見出しには選択背景が付きますが、本文側で別の見出しへ移ると、移動元の選択背景は自動的に解除されます。
- `Ctrl` / `Cmd`+クリックで複数の見出しを明示的に選択できます。この複数選択は本文の現在位置が変わっても保持されます。
- 見出しをドラッグすると、単一または複数のセクションを同じファイル内や別ファイルへ移動できます。
- 見出しの右クリックメニューから、そのセクションを別ファイルへ切り出せます。複数選択中は切り出しを利用できません。

### 検索・置換

- 「このファイルを検索」と「プロジェクトで検索」を切り替えられます。
- 検索結果にはファイルと見出しの文脈が表示されます。
- 現在のファイル内の置換と、プロジェクト全体の一括置換に対応します。
- プロジェクト全体を置換する前には確認画面が表示されます。
- 既定ではコメント行を検索・置換しません。`//` ボタン（ファイル内検索にもあります）をオンにすると、コメント行も対象になります。

## Idea

右サイドバーの電球アイコンから開きます。Ideaは「スレッド」と、その中に混在するIdea断片・資料で構成されます。

### スレッド一覧

- 検索欄でスレッド名、Idea本文、資料ファイル名、テキスト／Markdown資料の冒頭を絞り込みます。
- 「すべて」「スター」のフィルタを切り替えます。
- 新しいIdeaを入力し、追加先スレッドを選んで保存できます。
- クリップボタンから複数ファイルの取り込み、または新しいテキスト資料の作成ができます。
- スレッドを新規作成できます。

### スレッド詳細

- スレッド名の変更、スター、削除
- Idea断片と資料の追加、混在並べ替え
- Idea断片の編集・別スレッドへの移動
- 資料の別スレッドへの移動、別スレッドにも追加、現在のスレッドから削除
- 断片の削除
- 各断片の右下にあるボタンから、本文上の浮動カードとして開く
- 移動・削除・並び替えは、操作後の通知から元に戻せます。

ドラッグハンドルは、スレッド内のIdea・資料の並べ替えと、開いているCanvasへのドラッグ&ドロップに使います。本文へはドラッグ挿入されません。`Ctrl+Alt+I` を使うと、右サイドバーを開かずにIdeaを追加できます。

Ideaは専用アイコンからIdeaポップアップとして、資料は資料カードとして本文上へ開きます。同じ項目が既に開いている場合は、そのカードが最前面へ移動します。左アクティビティバーのカードアイコンから、現在開いているIdeaポップアップと資料カードをまとめて確認できます。

Ideaの管理単位は設定の「Ideaの管理単位」で選択できます。「作品ごとに分ける」ではワークスペースのフォルダごとに別々のIdeaを持ち、ワークスペースを切り替えると中身も切り替わります。「全作品で共有する」ではアプリに1セットだけ保存し、どのワークスペースでも同じIdeaを表示します。

## Plot

右サイドバーの本アイコンから開きます。

- **章**と**セクション**のカードで構成を管理します。
- セクションには `001`、`002` のような番号が自動で付きます。
- 章とセクションはドラッグして並び替えられます。
- セクションを別の章へ移動できます。
- 章を折りたたむと配下のセクションをまとめて隠せます。
- タイトルと本文を直接編集できます。
- Plotから資料を関連付けて開けます。
- 管理画面から全体を一覧できます。

## 資料

資料は独立した一覧ではなく、Ideaスレッドの中へ追加して整理します。

### 対応形式

- テキスト: `.txt`
- Markdown: `.md`
- 画像: `.png` / `.jpg` / `.jpeg` / `.webp`
- PDF: `.pdf`

### 資料の範囲

- 資料は現在の作品フォルダ専用です。
- 取り込んだファイルは作品フォルダ内の `.then/references/imports/` に保存され、作品フォルダと一緒に別端末へ移動できます。

Ideaの追加欄にあるクリップボタンから既存ファイルを取り込むか、新しい `.txt` / `.md` 資料を作成できます。同じ資料を複数のIdeaスレッドから参照できます。

資料を開くと、本文上に移動・サイズ変更可能なカードとして表示されます。カードはピン留め、折りたたみ、最前面表示、閉じるなどの操作ができます。テキスト資料はカード内で編集でき、画像のズームとPDFのページ操作も利用できます。

「このスレッドから削除」は通常、そのスレッドの参照だけを外します。最後の参照を外す場合は、資料ファイルもプロジェクトから削除する確認が表示されます。「資料ファイルを削除」はすべてのスレッドの参照と開いている同一資料カードも削除します。

## Idea Board

トップバーの「キャンバス」、またはIdeaペインのキャンバスボタンから開きます。

- Boardは現在の作品フォルダに保存されます。
- 複数のBoardを作成・選択できます。
- Board一覧では、ドラッグまたは上下ボタンで並び順を変更できます。
- 不要なBoardはゴミ箱へ移動できます。上部のゴミ箱ボタンから、削除日時、カード数、接続線数を確認して復元できます。
- テキストカード、資料カード、グループを配置できます。
- 余白のドラッグで盤面を移動し、カードは面全体をドラッグして移動できます。Shift／Ctrlを押しながら余白をドラッグすると範囲選択になります。
- テキストカードはダブルクリック、または選択してEnterで編集します。
- 編集中はカードのタイトルを追加できます。選択時の「表示設定」ではタイトルとカード色を変更できます（複数選択時は色をまとめて変更できます）。
- テキストカードを別のカード本体へドラッグし、「ここにまとめる」と表示された状態でドロップするとスレッド化できます。スレッドは縦のリストとして整列し、親カードのバッジでまとめて折りたためます。子カードはスレッド領域の外へ明確にドラッグしたときだけ外れます。
- ホイール操作で、ポインター位置を中心にキャンバスを滑らかに拡大・縮小できます。
- Ideaや資料をサイドパネルからクリックまたはドラッグして追加できます。
- カード同士を線、矢印、双方向矢印で接続できます。
- 接続線にはラベルを付けられます。
- カードの複製、削除、四隅からのサイズ変更、複数選択、グループ移動ができます。
- 選択したテキストカードをIdeaまたはPlotへ送れます。
- Undo／Redo、ズーム、全体表示に対応します。

設定で、カードの既定方向、既定フォント、キャンバスを別ウィンドウで開くかどうかを変更できます。

### 中間稿

右サイドバーの「中間稿」、またはCanvasの「稿」ボタンから開きます。現在の作品のBoardから選べます。

1. 「並べ替え」でボードの全テキストカードを確認します。矢印を初期順序に使用し、番号と本文抜粋で表示します。不要なカードは行の「−」で生成対象から除外でき、「＋」で戻せます。Canvas本体のカードには影響しません。
2. ドラッグハンドルまたは上下ボタンで順序を調整し、「この順序でテキストを生成」を押します。空カードは本文に含みません。
3. 「テキスト」で文章を編集します。最新版は自動保存され、本文画面でも同じ稿を参照できます。必要な文章を選択してコピー＆ペーストするか、「全文コピー」を使います。
4. Canvasの変更を取り込むときは「Canvasから再生成」を押し、順序を確定して新バージョンを生成します。編集済みの旧版は残り、バージョン選択から参照できます。

生成済みの版ではカード順・除外設定を直接変更できません。変更するときはCanvasから再取得してください。再取得後も最新版の本文は編集でき、版を切り替えても生成前の並べ替え・除外設定は保持されます。

中間稿の編集はCanvasや本文へ自動転記されません。本文のタイプライタースクロールと中間稿のスクロールは独立しています。

「書き出し」で選択中の版を `.txt` として保存できます。保存先は作品フォルダ内の `.then/boards/.intermediate-drafts/<boardId>/` です。各版の `v1.txt`、`v2.txt` などを他のエディタで読めます。Thenでの復元には `history.json` を使用するため、外部で編集した `.txt` は自動で取り込まれません。ボードをゴミ箱へ移すと中間稿も移動し、復元できます。

保存失敗・別画面との競合はペイン下部に表示されます。未保存の文章は維持されるので、再試行するか、必要な文言をコピーしてから「保存版を読み直す」を使用してください。デスクトップ版では、終了直前の未保存内容も次回そのボードを開く際に復元します。

## チェックポイント

トップバーの履歴アイコンから開きます。チェックポイントは、ワークスペース内の原稿と並び順を保存点として記録する機能です。

### 保存点を作る

「保存点を作成」を選び、名前と必要に応じてメモを入力します。保存点一覧では名前、日時、ファイル数、文字数を確認できます。

### 比較する

- 保存点と現在のプロジェクトを比較
- 2つの保存点を比較
- ファイルごとの差分、追加、削除、移動を確認

### 復元する

- プロジェクト全体を復元
- 選択したファイル／フォルダだけを復元
- フォルダの並び順も復元

現在のファイルと競合する場合は、次から選択します。

- 保存点の内容で置き換える
- 保存点の内容を別ファイルとして復元する
- 競合したファイルをスキップする

復元前には現在の状態が「復元前の退避」として自動保存されます。

## PDFとDOCXのエクスポート

トップバーの「エクスポート」から開きます。

### 出力する原稿

- ワークスペース内のファイルから出力対象を選択します。
- ファイルの順序を変更し、1つの文書として束ねます。
- ファイルごとの開始方法を指定できます。

### レイアウト

- B6、A5、A6、B5、A4、カスタムサイズ
- 天、地、ノド、小口の余白
- 出力フォント
- 段数と段間
- ヘッダー
- フッターとノンブル
- 奇数／偶数ページや章扉での表示制御

### 表紙・目次

設定の「表紙・目次」で、本文の前に表紙と目次を付けられます。順序は表紙→目次→本文です。

- **作品名**: 表紙・ヘッダー・出力ファイル名に使います。空欄ならフォルダ名です。
- **表紙**: 「文字」はタイトル・副題・著者名を本文の組方向で組みます（配置は天地中央／やや上寄せ、タイトルの大きさは本文の倍率で指定）。「画像」はPNG・JPEGをページ全面に余白なしで配置します。「画像の上にタイトルを重ねる」をオンにすると、画像の上に白または黒の文字でタイトル・副題・著者名を組みます。
- **目次**: 収録範囲は「ファイル単位」「見出し1まで」「見出し2まで」から選べます。
- 表紙・目次のページにはヘッダーとページ番号を付けず、本文の1ページ目を開始番号から数えます。見開きでは目次と本文を奇数ページから始めます。
- 表紙・目次の設定は変更した時点で作品ごとに記憶され、次にその作品を書き出すときも使われます。新しい作品では、直前に使った設定が引き継がれます。プリセットを切り替えても表紙・目次の設定は変わりません。
- 作品名・副題・著者名・表紙画像は作品フォルダの `.then` に保存されます。
- DOCXの目次は、Wordで開いたときに表示される「フィールドを更新しますか」で「はい」を選ぶとページ番号が入ります。

プレビューでページを確認し、「PDFを書き出す」または「DOCXを書き出す」を実行します。生成中は進捗が表示され、完了後に出力先を開けます。

設定でエクスポート画面を別ウィンドウにすることもできます。

#### 0.5.10で改善されたIME入力中の表示

日本語IMEの変換中は、直前に確定した行番号と現在行ハイライトを維持します。変換文字列によって折り返し位置が変わる場合も、入力を妨げないよう変換中の再計測は行わず、変換確定後に正しい表示行へ更新します。

#### 0.5.9で追加された本文表示補助

「行番号を表示」「現在行をハイライト」「「」内を色分け」は初期状態ではオフです。必要な機能だけ個別に有効にできます。

- 行番号はMarkdownの段落番号ではなく、画面上で折り返された実際の表示行を先頭から連番にします。縦書きでは各表示列の上、横書きでは各表示行の左に表示され、ウィンドウ幅、本文表示幅、フォントが変わると再計算されます。
- 現在行のハイライトは、段落全体ではなくキャレットがある表示列／表示行だけを控えめな背景色で示します。行番号と同時に使うと、該当する番号も強調されます。
- 「」内を色分けは、対応する鉤括弧で閉じられた会話文を鉤括弧ごと落ち着いた色にします。閉じ鉤括弧がない入力途中の範囲は色分けしません。

#### サイドペインのホバー表示

外観設定の「サイドペインの表示」では、「左右とも常に表示」「左右ともホバー表示」「左側のみホバー表示」「右側のみホバー表示」を選択できます。ホバー表示にしたペインは通常時に画面端へ隠れ、その分だけ本文領域が広がります。対応する画面端へマウスポインターを移すと、ペインが本文の上へ重なって表示されます。ペイン内へキーボードフォーカスを移した場合も表示を維持します。

- 各テーマで、行番号、改行記号、現在行ハイライトをスクロール領域の外側に配置し、ガラス効果などによる座標ずれを防ぎました。

#### 0.5.12で改善された狭幅表示

- Windowsの半画面表示など、狭いウィンドウでも本文領域が実際の表示幅に収まり、タイプライタースクロールの固定位置が可視領域を基準に計算されます。
- 縦書きの固定位置を50%未満にした場合も、文書の先頭行を指定位置までスクロールできます。
- Zoneモードでは、UI表示倍率にかかわらず画面右端へポインターを移動すると右サイドバーを表示できます。

#### 0.5.11で追加・変更されたテーマ

- 「Standard」は「Red」と同じ白基調の面構成で、上部バーを白、見出し、選択状態、主要操作のアクセントを黒に統一したライトテーマです。
- 従来の「Signal Red」は「Red」に改名しました。赤をアクセントとする配色はそのままです。
- 「Default」は引き続き白とネイビーのライトテーマとして利用できます。
- エディタ集中表示では、上下端の7pxのホバー領域を残しつつ、非表示時の上部グラデーションと上下バーの影をなくしました。

## 困ったときは

### 前回のワークスペースが開かない

フォルダが移動・削除されていないか確認し、起動ポータルから現在の場所を選び直してください。

### 保存状態が「エラー」になる

ファイルやフォルダの書き込み権限、別アプリによるロック、空き容量を確認してください。詳細は画面のエラー表示に示されます。

### ルビ・圏点・縦中横を適用できない

範囲を選択し、改行をまたいでいないことを確認してください。カーソルを置いただけの状態や複数行の選択では適用できません。

### 資料やチェックポイントの操作が使えない

ワークスペースを開いていることと、Tauriデスクトップ版で実行していることを確認してください。

### Windowsがインストーラーを警告する

現在の配布インストーラーはコード署名されていないため、Windows SmartScreenが警告を表示する場合があります。必ず公式の[GitHub Releases](https://github.com/maybefix/Then/releases)から取得してください。
