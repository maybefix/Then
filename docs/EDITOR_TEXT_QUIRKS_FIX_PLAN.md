## 工程2: 仕組みの説明

### 言葉

- **検索バー**: 本文の上に出る、Ctrl+F の検索と置換（「置換」「すべて」）。
- **検索サイドバー**: 左の「プロジェクト検索」。大文字小文字の区別・正規表現・コメントを含むの切り替えがある。
- **地付き**: 行を行末（縦書きなら下）へ寄せる指定。今の書き方は `[(al:end)]`。旧来の書き方として、行頭の `>>` と `［＃地付き］` も読める。

### 1. 検索の2つの作り

| | 検索バー（`src/search/editorFindReplace.ts`） | 検索サイドバー（`src/search/textSearch.ts`） |
|---|---|---|
| 一致の探し方 | 検索語の前後の空白を削り、本文と検索語を小文字にしてから `indexOf` で探す | 検索語をそのまま正規表現に直し（記号は文字として扱う）、大文字小文字を区別しない印 `i` を付けて、元の本文の上で探す |
| 位置 | 小文字にした本文の上の位置を、元の本文の位置として使う（癖3の原因） | 元の本文の上の位置 |
| 置換後の文字列 | 書いたとおり | 書いたとおり（正規表現を使わないとき） |
| コメント行 | 「コメントを含む」が切ってあれば飛ばす | 同じ |

### 2. Ctrl+I（`toggleEmphasisSelection`）

選んだ文字の外側が `[` と `(em…)]` なら外し、選んだ文字そのものが `[…(em…)]` なら中身だけにする。それ以外は `[…(em,goma)]` で囲む。青空文庫形式の圏点 `《《…》》` は、外す側で見ていない（癖6）。Ctrl+B（太字）は、外側の `**` と、選んだ文字そのものの `**…**` の両方を見て外す。

### 3. 文章方向と記法のクリア

- 文章方向（`applyDirectionToSelection`）: 選択を含む各行から、前の指示（`[(al:…)]` と行頭の `>>` と空白）を外し、行末に新しい `[(al:…)]` を付ける。`［＃地付き］` は外さない（癖8）。
- 記法のクリア（`clearNotationInLine`）: 選択に触れているルビ・圏点・縦中横・太字を外し、行の `[(al:…)]` はすべて外す。行頭の `>>` と `［＃地付き］` は外さない（癖7）。
- 読み込み（`src/editor/ast/documentAst.ts` の770行付近）では、行頭の `>>` と、行頭の `［＃地付き］` を地付きとして読む。
