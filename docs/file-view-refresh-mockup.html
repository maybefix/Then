第一章　雨の匂い

静寂のなかで、目はゆっくりと開いた。

駅舎の屋根を打つ雨の音だけが、遠い記憶のように続いている。

彼は濡れた切符を指でなぞり、ホームの向こうに人影を探した。

朝はまだ来ない。けれど雲の端には、淡い光が滲み始めていた。

「ここで待てばいい」手紙には、ただそれだけが書かれていた。
