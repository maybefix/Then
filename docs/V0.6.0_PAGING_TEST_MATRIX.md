## 判定方針

- 「確認済み」は実画面または対応する回帰テストで再現条件を通したものに限定する。
- 未踏条件は残存バグと同一ではないが、潜在バグがあり得る範囲として扱う。
- v0.6.0完成判定前に高優先度をすべて実画面確認し、見つかった不具合を個別の再現テストへ固定する。
