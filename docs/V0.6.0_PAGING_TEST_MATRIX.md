## 未踏または確認が薄い高リスク条件

| 優先度 | 条件 | 主な懸念 |
| --- | --- | --- |
| 高 | 縦送り × スクロールバーを高速ドラッグ | 中間ページを飛び越したときの停止位置 |
| 高 | IME変換中にページ境界をまたぐ | composition中と確定後の断片再計算 |
| 高 | ウィンドウ最大化・復元、左右ペイン開閉 | ページ寸法変更後の現在ページ保持 |
| 高 | ちょうどページ末尾になる文書 | 総ページ数の境界丸め、空の最終ページ |
| 中 | 空行が連続する文書 | 行番号・改行記号・ページ数の整合 |
| 中 | 非常に長い1段落 | widows/orphansと断片位置 |
| 中 | フォント変更・Webフォント読込完了 | 文字寸法変更後のページ保持 |
| 中 | Undo/Redoでページ数が増減 | キャレットと履歴復元位置 |
| 中 | 見出しジャンプ直後の入力 | ジャンプ補正と編集補正の競合 |
| 低 | 高DPI・UI表示倍率変更 | 小数座標の丸めとscroll-snap境界 |

## 判定方針

- 「確認済み」は実画面または対応する回帰テストで再現条件を通したものに限定する。
- 未踏条件は残存バグと同一ではないが、潜在バグがあり得る範囲として扱う。
- v0.6.0完成判定前に高優先度をすべて実画面確認し、見つかった不具合を個別の再現テストへ固定する。
