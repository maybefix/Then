# Markdown表

本文エディタで、見出し行・区切り行・データ行からなるMarkdown表を表示できます。
縦書きではセル内の文字も縦書きになり、横書きに切り替えると表も横書きになります。

```markdown
| 品名 | 数量 | 備考 |
| :--- | ---: | :---: |
| りんご | 12 | 青森県産 |
| みかん | 3 | 甘い果物です |
```

セルをクリックして直接編集できます。空のセルもクリックして入力できます。
表の行は罫線付きのグリッドで、間にMarkdownの記号を寸法ゼロで挟むため、
描画エンジンによってはクリック位置からキャレットを決められません
（WebView2ではカーソルが元の位置に残ります）。そのため単独のクリックでは、
セル側で文字の描画位置を測ってキャレットを置きます。
ドラッグでの範囲選択・ダブルクリックは従来どおりブラウザに任せます。
表の外の行から矢印キーで表に入ると、ブラウザは行末のパイプや区切り行など
隠れた記号の上にキャレットを置きます。そこは寸法がないためカーソルが見えず、
入力するとセルの外へ文字が入るので、いちばん近いセルの中へ引き戻します。
矢印キーでセル間を移動するときは、非表示の区切り記号と区切り行を飛ばします。
`Tab` / `Shift+Tab` で次・前のセルへ、`Home` / `End` でセルの先頭・末尾へ移動できます。
`Enter` は次のデータ行の同じ列へ移動します。最終行からは表の後の本文へ移動します。
文書先頭の表では、見出しセルから縦書きなら右矢印、横書きなら上矢印で
表の前に空行を作り、そこへ移動できます。既に前の行がある場合はその行へ移動します。
セル先頭のBackspace・末尾のDeleteでは区切り記号を削除しません。
`Ctrl+P` のコマンドパレットで「表を挿入…」を選ぶと、列数（1〜10）と
データ行数（1〜20、見出しを除く）を指定して作成できます。
挿入後は最初の見出しが選択されるので、そのまま名前を入力できます。

列の配置は、対象セルにカーソルを置き、`Ctrl+P` から
「表：この列を中央揃え」「表：この列を開始揃え」「表：この列を終了揃え」で変更します。
開始・終了は、横書きでは左・右、縦書きでは上・下に対応します。
行を増やす場合は、Markdownの `| 内容 | 内容 |` を改行して追加します。
区切り行の `:---`・`---:`・`:---:` で、セル内の開始側・終了側・中央揃えを指定できます。
セル内にパイプを記述する場合は `\|` とします。

パイプと区切り行は画面上では隠し、セルの内容と罫線だけを表示します。
保存・コピーされる本文には元のMarkdown記法が残ります。
新規作成した表のセルには余分な半角スペースを挿入しません。
既存の表のセル両端にある半角スペース・タブはMarkdownの余白として非表示にします。
空セルをクリックするだけでは本文は変わりません。IME変換中は入力領域を保ち、
確定した文字だけを本文に反映します。
セル内の太字などの追加記法は、この表表示ではそのままのテキストになります。

列の幅は、その列でもっとも長いセル（見出しを含む）に合わせます。
同じ表の各行は同一の列幅を共有するため、行をまたいでも罫線がそろいます。
短い表は必要な分だけの大きさになり、全体が本文の幅（縦書きでは高さ）を
超える場合だけ、各列の比率を保ったまま縮めて折り返します。
1列が極端に長いときは上限で頭打ちにし、ほかの列がつぶれないようにします。

表は通常の本文と同じ編集領域を使用します。表にカーソルが出入りしても表示方式を
切り替えず、タイプライタースクロールの位置を保ちます。

開発確認: `npm run test:markdown-tables` / `npm run test:table-navigation` /
`npm run test:markdown-table-ime` / `npm run build`
クリック位置からの文字送りは描画結果に依存するため、実際の画面で確認します。
