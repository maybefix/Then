## 工程2: 仕組みの説明

### 言葉

- **圏点**: 文字の脇に付ける点。Then では `[語(em,goma)]` と書く。青空文庫風の `《《語》》` も読める。
- **付け外し（トグル）**: 付いていなければ付け、付いていれば外す操作。Ctrl+B（太字）と Ctrl+I（圏点）がこの形。

### 1. 右クリックの「圏点」で起きること

1. 右クリックしたときの選択の控え（開始・終了・文字列）を、メニューが覚える。
2. 「圏点」を押すと `applyInlineNotation(控え, "emphasis")`（`src/editor/editorNotationActions.ts` 69行）が呼ばれる。
3. 控えを今の本文の長さに収め直し、1行の中でなければ「単一行の範囲を選択してください」で終わる。
4. 選んだ文字を、中身を見ずに `[選んだ文字(em,goma)]` に書き換え、カーソルをその後ろに置く。
5. 通知「圏点を反映しました」。メニューは JSX の側で閉じる。

### 2. Ctrl+I で起きること

`applyEmphasisShortcut` → `toggleEmphasisSelection`（`src/editor/selectionEdits.ts` 264行）。次の順に見て、当てはまれば外し、どれでもなければ付ける。

1. 選択のすぐ外が `[` と `(em…)]` なら、外す（中身だけを選んだ場合）。
2. 選択そのものが `[…(em…)]` なら、外す（全体を選んだ場合）。
3. 選択のすぐ外が `《《` と `》》` なら、外す。
4. 選択そのものが `《《…》》` なら、外す。
5. どれでもなければ `[選んだ文字(em,goma)]` を付ける。

付けたときの結果とカーソルの位置は、右クリックの4と同じ。通知は出さない。

### 3. 保存

書き換えた本文は、ふだんの入力と同じ経路で保存される。保存形式は変わらない。

## 工程5: 案

### 直し方

**案A（勧め）: 右クリックの「圏点」を、Ctrl+I と同じ付け外しにする。**
`applyInlineNotation` の圏点の場合だけ、`toggleEmphasisSelection` の結果で書き換える。2章2の1〜4に当たれば外し、どれでもなければ今と同じく付ける。外したときの通知は「圏点を解除しました」（見出しの「見出しを解除しました」に揃える）。付けたときは今と同じ「圏点を反映しました」。
- 利用者から見て: 同じ選択なら、右クリックでも Ctrl+I でもコマンドパレットでも同じ結果になる。`《《傍点》》` も外れる。
- 手間: 小さい（関数の中の10行ほど）。処理は Ctrl+I で使っているものなので、新しい書き換えの規則は増えない。

**案B: 圏点の付いた範囲では、右クリックの「圏点」を押せないようにする。**
- 利用者から見て: 二重にはならないが、外すには Ctrl+I か「記法をクリア」を使う。押せない理由は画面に出ない。
- 手間: JSX で、メニューを開いたときの本文を読んで判断する処理が要る。

**案C: 案A に加えて、外すときはメニューの項目の文言を「圏点を外す」に変える。**
- 利用者から見て: 押す前に、外れることが分かる。
- 手間: メニューを開いたときに本文を読んで、外れるかどうかを決める処理を JSX に足す。Ctrl+I とコマンドパレットの「圏点（傍点）」は付け外しでも文言が変わらないので、そこだけ食い違う。

### 決まったことからの細かい扱い（工程7で、この形で作る）

**縦中横（右クリックの「縦中横」、コマンドパレットの「縦中横」）**: `src/editor/selectionEdits.ts` に `toggleTcySelection` を足す。圏点の付け外しと同じ順に見る。

1. 選択のすぐ外が `[` と `(tcy…)]` なら、外す（中身だけを選んだ場合）。
2. 選択そのものが `[…(tcy…)]` なら、外す（全体を選んだ場合）。中身に `[` `]` を含むものは当てはめない（`[a(tcy)][b(tcy)]` を1つと見ないため）。
3. どれでもなければ、今と同じく `[選んだ文字(tcy)]` を付ける。

外したときの通知は「縦中横を解除しました」。縦中横には青空文庫風の書き方がないので、`[…(tcy)]` だけを見る。

**ルビ（右クリックの「ルビ...」とコマンドパレットの「ルビ…」→ ダイアログの「反映」）**: `src/editor/selectionEdits.ts` に `applyRubyToSelection` を足す。すでに付いたルビに当たれば、書き方はそのままで読みだけを置き換える。

1. 選択のすぐ外が `[` と `(rb,…)]` なら、`[本文(rb,新しい読み)]` にする（中身だけを選んだ場合）。
2. 選択そのものが `[本文(rb,…)]` なら、同じく置き換える（全体を選んだ場合）。
3. 選択のすぐ前が `｜`、すぐ後ろが `《…》`（`《《` ではない）なら、`｜本文《新しい読み》` にする。
4. 選択そのものが `｜本文《…》` なら、同じく置き換える。
5. 選択が漢字など（読み込みと同じ `[一-龠々〆ヶ]`）だけで、すぐ後ろが `《…》`、すぐ前が漢字などでない（＝ルビの付く語の全体を選んでいる）なら、`本文《新しい読み》` にする。
6. 選択そのものが `漢字《…》` で、すぐ前が漢字などでないなら、同じく置き換える。
7. どれでもなければ、今と同じく `[選んだ文字(rb,読み)]` を付ける。

読みは今と同じく `sanitizeNotationArgument` で整える（改行と `]` `)` を空白に）。青空文庫風の書き方（3〜6）では、`《` `》` も空白にする（読みの中に入ると、ルビの終わりがずれるため）。通知は、付けたときも置き換えたときも「ルビを反映しました」。ダイアログの読みの欄は、今と同じく空で開く。

**カーソル**: どの場合も、書き換えた記法の後ろに置く（今の、付けたときと同じ）。外したときは、残った文字の後ろ。

**変えないもの**: 選択がルビ・圏点・縦中横の中身の一部だけのとき（たとえば `[東京(rb,…)]` の「東」だけ）は、今と同じく外側に付ける。メニューの項目、押せる条件、ダイアログの文言、Ctrl+I は変えない。
