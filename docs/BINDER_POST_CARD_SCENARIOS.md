# Canvas の投稿のカード：場面ごとの比べ表

確認1の「決めてほしいこと」を、具体的な場面に当てはめて、案ごとに何が起きるかを並べた。
手順書は [BINDER_POST_CARD_PLAN.md](BINDER_POST_CARD_PLAN.md)。

- この表は、コードを読んで出した**見込み**。まだ動かしていない。
- 決まった案は、そのままテストと実機確認の場面に使う（最後の節）。

---

## まず、言葉を3つだけ

| 言葉 | 意味 |
|---|---|
| 投稿 | 右のペイン「アイデア」に書き流す1件。ライブラリ全体で1本のファイルに持つ |
| 投稿のカード | この作業で足すカード。投稿の ID だけを覚えていて、本文は毎回投稿から映す |
| コピーのカード | 昔、Idea の「Canvas へ送る」で作ったテキストのカード。文は写しで、「どの断片から来たか」の印を持つ |

したいことは1つだけ。**Canvas に、投稿そのものを指すカードを置けるようにする。**

---

## 場面の舞台

どの場面も、ライブラリ「本棚」を使う。

- 作品A・作品B と、ライブラリ直下がある。
- 投稿（ライブラリで共有）
  - P1「灯台の夢」（作品A で書いた。受信箱にある）
  - P2「港で拾った言葉」（作品B で書いた）
  - P3「夜の郵便局」（作品A。あとで「ノートにする」でノート `素材/夜の郵便局.md` にした）
  - P4「続き：波の音」（P1 への返信）
- 作品A のボード「構想」と、ライブラリ直下のボード「全体」がある。

## 決めごと1：保存の形（T1・T4・T5・T12）

| 案 | ボードのファイルに書くもの | Then での見え方（T1・T4・T5） | 外へ写して Obsidian で開く（T12） | 古い版の Then で開く |
|---|---|---|---|---|
| **A（勧め）** Then 固有の種類 | `"type":"post","post":"P1 の ID"` | ✅ 3つとも投稿のカード。本文はいつも投稿のいま | ⚠️ カードが出ない。Obsidian でボードを保存すると、そのカードは消える（今の資料のカードも同じ） | 4-2 より後の版: 出ないが残る。それより前: 保存で消える |
| B テキストに写しと印 | `"type":"text","text":"灯台の夢","thenPost":"P1 の ID"` | ✅ 投稿のカード。投稿が変わると、Then が写しも書き直す | ✅ 写しの文がテキストで出る（古いことがある）。Obsidian で直しても、Then が投稿で上書きする | ✅ ふつうのテキストカード（写しの文） |
| C `link` に Then の URL | `"type":"link","url":"then://post/…"` | ✅ 投稿のカード | ⚠️ 開けないリンクのカードが出る | 4-2 より後の版: 出ないが残る |

**比べどころ:** Then の中の見え方はどれも同じ。違いはボードの外。ボードは `.then/` の中にあり、Obsidian の保管庫にはふつう出ない。B は外で読めるが、ボードの書き込みが増え、テキストカードを扱う処理すべてに除外を足す。

**T3**　そのあいだ、投稿のペインでも P1 の本文に手を入れていた。

| 案 | T2 | T3 |
|---|---|---|
| **A（勧め）** 直せて、書き戻す | ✅ 0.5 秒止まると投稿 P1 が「灯台の夢。光が三回」になる。投稿のペインの P1 もその場で変わる。投稿に「編集済み」の時刻が付く | ⚠️ 後から書いたほうが書けない。カードが後なら選ぶ画面（5-8）、ペインが後ならペインの文が入力欄へ戻る。どちらの文も黙っては消えない |
| B 表示だけ | ➖ 直せない。ダブルクリックで右のペインの P1 へ動き、そこで直す | ➖ 起きない |

## 決めごと4：4-5 で残ったコピーのカード（M1〜M5）

| 案 | M1 作品のボード | M2 ライブラリ直下のボード | M3 直した文 | M4 ノートにした | M5 消した投稿 |
|---|---|---|---|---|---|
| **A（勧め）** 含める。直下は全作品の記録から引く | ✅ 投稿のカード（同じ場所・大きさ・色・矢印） | ✅ 投稿のカード。元の断片が2つの作品に見つかれば ➖ | ➖ テキストのまま | ✅ 作品のボードはノートのカード（今のまま）。直下のボードは投稿のカード | ➖ テキストのまま |
| B 含める。作品のボードだけ | ✅ 同上 | ➖ テキストのまま | ➖ | ✅ ノートのカード（今のまま）。直下は ➖ | ➖ |
| C 含めない | ➖ テキストのまま | ➖ | ➖ | ✅ ノートのカード（4-5 のまま）。直下は ➖ | ➖ |

**手元の Books では（次に新しい版で開いたとき）:** Idea の移行で元の断片が「受信箱から外した投稿」になり、すぐあとにこの移行が走る。

- A: 2枚とも投稿のカードになる。通知は「…コピーのカード2枚を投稿のカードに置き換えました」。
- B: 作品のボードの1枚だけ。通知は「…1枚を…」。
- C: 何も変わらない。

**どの案でも:** 置き換える前のボードは `.then/backups/copy-cards-<日時>/` に残る。文が元と違うカードは置き換えない。2回目に開いても何もしない。

## まとめ：勧めの組み合わせで

| 場面 | 結果 |
|---|---|
| T1 置く | ✅ 「資料を追加」の一覧から置ける |
| T2 直す | ✅ 投稿に書き戻す |
| T3 2か所で直す | ⚠️ 後から書いたほうが書けない。文は消えない |
| T4 ほかの作品の投稿 | ✅ 置ける。見出しに作品名 |
| T5 ライブラリ直下 | ✅ 置ける |
| T6 消す・戻す | ⚠️ 薄いカード → 戻すと元通り |
| T7 ノートにした | ✅ 投稿のカード＋ノートの札 |
| T8 返信 | ✅ その投稿の本文だけ |
| T9 送る | ✅ 投稿のカードのまま |
| T10 原稿を作る | ➖ 入らない |
| T11 投稿にする | ➖ 今のまま（③ を選べば投稿のカードに変わる） |
| T12 Obsidian | ⚠️ 出ない（ふつうは見えない場所） |
| M1・M2 残ったコピーのカード | ✅ 投稿のカードになる |
| M3・M5 | ➖ テキストのまま |
| M4 | ✅ 作品のボードはノートのカード、直下は投稿のカード |

- **文がなくなる場面はない。** 置き換わるのは、文が元とまったく同じコピーのカードだけ。カードで直した文は、書けなければ選ぶ画面か入力欄に残る。

## テストと実機確認への使い方

| 場面 | 自動テスト | 実機確認（一時ライブラリ） |
|---|---|---|
| T1・T4・T5 | jsdom: 一覧から置く・見出し・作品名・直下のボード | 「資料を追加」から置き、再起動しても残るか |
| T2・T3 | jsdom: 0.5 秒後に1回、ハッシュ付きで頼む／外で直されていたら選ぶ画面 | カードで直して投稿のペインと `posts.jsonl` を見る。ペインでも直して衝突させる |
| T6〜T8 | jsdom: 消えた・ノートの札・返信 | 消して戻す、札を押す |
| T9・T10 | jsdom: 送ってもカードのまま／原稿の一覧に入らない | 送って送り先で開く |
| T11 | （③・K1 を選んだとき）jsdom | 「投稿にする」を押す |
| M1〜M5 | Rust: 置き換わる・置き換えない・直下・2つの作品・2回目・バックアップ・失敗で戻る | 移行前のボードを書いた一時ライブラリで起動し、ハッシュで前後を比べる |
| 全部 | ボードのほかのカード・線・知らない種類のカードがそのまま | 別ウィンドウの Canvas でも同じか |
