# Then コメントアウト 仕様

確定日: 2026-09-29
状態: 実装済み（v1）

## 0. 目的

本文中にメモや没稿を残せるコメント記法を導入し、エディタ上でコメントの表示／非表示をアプリ全体で切り替えられるようにする。コメントは原稿の一部ではなく、文字数・行番号・校正・書き出しのいずれにも影響しない。

## 1. 記法

### 1.1 行コメント `//`（主記法）

- 行頭が `//` で始まる行を、その行全体のコメントとする。
- 行頭の半角空白・全角空白（`　`）は許容する。字下げした行もコメントにできる。
- 全角の `／／` はコメントとして扱わない（本文での誤判定を避けるため）。
- 行の途中からのコメント（`本文 // メモ`）は扱わない。本文やURLに `//` が現れるため。
- 複数行コメントは `//` 行を連ねて表す。`/* */` は採用しない。
- コードフェンス内の行はコメントとして扱わない。
- エスケープ: 行頭（先頭空白の後）の `\//` は本文の `//` として扱い、表示・書き出しでは `\` を除く。

### 1.2 HTMLコメント `<!-- -->`（互換記法）

Markdown互換のため、HTMLコメントもコメントとして扱う。判定は行単位で、行頭と行末の両方を見る。

- 1行: 行頭（先頭空白の後）が `<!--` で始まり、行末（末尾空白の前）が `-->` で終わる行はコメント。
- 複数行: 行頭が `<!--` で始まる行から、行末が `-->` で終わる行までの全行をコメントとする。
- 閉じ `-->` が見つからない `<!--` はコメントとして扱わない（本文のまま）。閉じ忘れで以降の全文が消えることを防ぐ。
- 行の途中に置かれたHTMLコメント（`本文<!-- メモ -->本文`）はv1では対象外。
- コードフェンス内は対象外。

### 1.3 入力補助

日本語IMEでは `/` キーが「・」になるため、ショートカットでの切り替えを主な入力手段とする。

- `Ctrl+/`: 選択範囲に含まれる行（選択がなければカーソル行）のコメント化／解除をトグルする。
  - 対象行がすべて `//` コメントなら解除、それ以外ならすべてに `//` を付与する。
  - 付与は行頭（先頭空白の後）に `//` を挿入する。
  - HTMLコメントの付与は行わない。`<!-- -->` 行に対して実行した場合は `<!--` `-->` を外して解除する。
- コマンドパレットにも同じコマンドを登録する。

## 2. 表示

### 2.1 表示／非表示の切り替え

- 設定はアプリ全体で1つ持ち、永続化する（文書・タブごとには持たない）。
- 切り替え手段: コマンドパレット、ショートカット（割り当ては実装時に既存と衝突しないものを選ぶ）、設定画面の本文設定。
- 切り替え時は、カーソル行の画面上の位置を保つ。自動スクロールでカーソルを追わない。

### 2.2 表示中

- コメント行は記号（`//`、`<!--`、`-->`）を含めて表示し、テーマ変数で定義した弱い色で描く。
- 通常どおり編集できる。

### 2.3 非表示中

- コメント行は行ごと畳み、レイアウト上の領域を取らない。
- 非表示のコメント行にカーソルを置かない（§3）。

## 3. カーソル・選択・タイプライタースクロール

- 非表示中は、選択範囲の端点が非表示コメント行の中に来ないよう正規化する。
  - 矢印キーでの移動は非表示行を飛ばす。
  - カーソルがコメント行にある状態で非表示へ切り替えた場合は、直後の表示行（なければ直前の表示行）の行頭へ移す。
- 以上により、タイプライタースクロールが参照するキャレットは常に描画済みの行上にあり、中央寄せは既存の処理のまま動く。
- 非表示中に、非表示コメントをまたいだ範囲を削除・切り取りした場合はコメントも一緒に消える（折りたたみと同じ扱い）。コピーではコメントを含む元テキストをコピーする。
- ページ表示モードでは、表示／非表示によってページ割りが変わる。

## 4. 行番号

- コメント行は、表示中・非表示中を問わず行番号を消費しない。表示を切り替えても本文の行番号は変わらない。
- 表示中のコメント行には番号を振らない。
- ステータスバーの行位置表示は元テキストの行番号であり、コメント分だけ行番号表示とずれる。

## 5. 検索・置換

- 検索オプションに「コメントを含む」（オン／オフ）を追加する。既定はオフ。`TextSearchOptions` に項目を追加する。
- オフ: コメント行は検索・置換の対象外。「すべて置換」もコメントを変更しない。
- オン: コメント行も対象。非表示中にコメント内のマッチへ移動したときは、そのコメントのまとまり（連続するコメント行）だけを一時的に表示し、カーソルがそこから出たら再び畳む。

## 6. 集計・解析

コメント行は次のすべてから除外する。

- 文字数（全体、見出し区間とも）
- アウトライン（`// # 見出し` は見出しにならない）
- 原稿用紙換算・改ページ計算
- 校正（`//` 行を既存の `<!-- -->` と同じくマスクする）

## 7. 書き出し

- ASTの `LineKind` に `"comment"` を追加し、書き出し用ブロックの生成時に除外する。Vivliostyle、印刷HTML、docx、Web小説投稿用テキストのすべてが同じ経路でコメントを落とす。
- Vivliostyleに渡すHTMLへは `<!-- -->` として残さず、出力しない。
- コメント行は段落を分けない。段落の途中にあるコメント行は存在しないものとし、前後の行は1つの段落として結合する。
- コメントを書き出しに含めるオプションはv1では設けない。

## 8. 保存形式

- `.txt`、`.md` とも、記法（`//`、`<!-- -->`）をそのまま保存する。`//` は標準Markdownではないが、独自ルビ記法などと同様にThenの原稿形式として扱う。

## 9. v1の対象外

- 行の途中からのコメント（`//`、`<!-- -->` とも）
- `/* */` ブロックコメント
- 全角 `／／`
- 書き出しにコメントを含めるオプション
- 文書・タブごとの表示状態
