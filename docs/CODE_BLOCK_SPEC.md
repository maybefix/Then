# Then コードブロック・行内コード 仕様

作成日: 2026-09-29
状態: 仕様策定中（§9 の未決事項あり）

## 0. 目的

技術文書にもThenを使えるよう、コードブロックと行内コードを本文と区別して扱う。あわせて、各機能に散らばっているコードブロック判定を1か所にまとめる。

現状、コードブロックの判定は次の4か所にあり、規則が一致していない。

| 場所 | 現状の規則 |
| --- | --- |
| `src/editor/ast/documentAst.ts`（コメント判定） | ` ``` ` / `~~~` 行ごとに内外を反転 |
| `src/proofread/context.ts` | 同上 |
| `src/proofread/candidates.ts` | 同上 |
| `src/editor/markdownTables.ts` | 記号の種類と長さを照合（CommonMark寄り） |

AST本体・エディタ表示・書き出し・文字数はコードブロックを認識していない。

## 1. 判定規則（全機能で共通）

### 1.1 コードブロック

- 開始行: 行頭の半角空白0〜3個の後に、`` ` `` を3個以上、または `~` を3個以上。その後に言語名などの情報文字列を置ける（`` ` `` の場合、情報文字列に `` ` `` を含められない）。
- 終了行: 開始と同じ記号を、開始と同じ数以上並べた行。後ろには空白のみ置ける。
- 開始行と終了行の間の行がコードの中身。開始行・終了行（フェンス行）もコードブロックの一部とする。
- **閉じないフェンスはコードブロックにしない**（本文のまま）。コメントの `<!--` と同じ扱い。
- インデントコードブロック（行頭4スペース）は扱わない。字下げした本文を誤判定するため。
- 判定は `documentAst.ts` の1関数に集約し、コメント判定・校正・表の判定はすべてこれを使う。

### 1.2 行内コード

- `` ` `` で囲んだ範囲（同じ数のバッククォートで開閉）。改行はまたがない。
- 行内コードの中ではルビ・圏点・太字などの記法を解釈しない。
- コードブロックの中では行内コードを解釈しない。

### 1.3 コメントとの関係

- コードブロック内の `//` や `<!-- -->` はコード（本文）であり、Thenのコメントにはならない。
- フェンス行ごと `//` を付けた行はコメントになる。したがって、コードブロック全体の各行に `//` を付ければ、ブロックごとコメントアウトできる。

## 2. AST

- `LineKind` に `"code"` を追加する。フェンス行と中身の行の両方が `"code"`。フェンス行かどうかと情報文字列を行に持たせる。
- `"code"` 行では、見出し・リスト・地付き・記法・コメントを解釈しない。
- 行内コードは `InlineMarkup` の新しい種類（`"code"`）とする。
- 判定は複数行にまたがるため、コメントと同じく変更のたびに全行を再判定し、種類が変わった行だけを解析し直す。

## 3. エディタ表示

- コードも縦書きで表示する（横書き設定では横書き）。等幅フォントを使い、背景色で本文と区別する。
- 空白・インデントは詰めずにそのまま表示する。
- 長い行は折り返す（タイプライタースクロールと行番号の計算を本文と同じ仕組みで保つため）。
- 行内コードは等幅フォントと背景色で表示する。
- フェンス行（` ``` `）はカーソルがないときも表示する（ブロックの境界として必要なため）。表示を控えめにするかは実装時に調整する。

## 4. 文字数

- 設定「コードの文字数を数える」を追加する（アプリ全体）。コードブロック（フェンス行を除く中身）と行内コードの中身の両方に適用する。
- 既定値はオン（現状と同じ数え方）。
- アウトラインの見出し区間の文字数、プロジェクト全体の文字数にも同じ設定を適用する。

## 5. 校正・検索

- 校正は現状どおりコードを検査対象から外す（判定だけを共通化する）。行内コードも対象外。
- 検索・置換はコードも対象とする（オプションは設けない）。

## 6. 書き出し

- Vivliostyle・印刷HTML: §9-1 で決める。
- docx: 等幅フォントの段落スタイルで出力し、空白を保つ。
- Web小説投稿用テキスト: フェンス行を含めて原文のまま出力する（記法変換をしない）。

## 7. 編集補助

- コードブロック内で `Tab` を押すとインデントを挿入し、`Shift+Tab` で1段戻す。複数行を選択しているときは各行に適用する。インデントの単位は §9-3 で決める。
- コードブロックの外では `Tab` の挙動を変えない（表のセル移動などを維持する）。
- コードブロック内の `Ctrl+/` は §9-2 で決める。

## 8. 対象外（v1）

- 構文ハイライト
- インデントコードブロック
- コードブロックの折りたたみ・行番号の別表示
