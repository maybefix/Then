# Then独自記法の手引き

確認日: 2026-10-11
対象: 現在のソースコード（package.jsonのバージョンは0.6.6）

Thenの原稿は、Markdownを基本に、ルビや縦書きのための記法を加えて書きます。この手引きでは、Then独自の書き方と、標準Markdownとは扱いが異なる部分を説明します。見出しや太字など、Markdownと共通する記法の説明は省いています。

AIに新しい原稿を書かせるときは、以下の「基本の記法」にそろえると、書き方が混在しません。これはAIへの指定をそろえるための方針です。Thenは後述の互換記法も読み取れます。

## 基本の記法

### コメントアウト

原稿に残したいメモや没稿は、行頭に半角の `//` を付けてコメントにできます。コメントは原稿ファイルに残りますが、本文の文字数、アウトライン、校正、PDF・DOCX・投稿用テキストの書き出しには含まれません。通常のファイル保存やコピーでは残るため、メモごと削除する機能とは異なります。

```text
// この場面は、あとで書き直す。
　主人公は駅の時計を見上げた。
// 別案：時計ではなく、発車案内を見せる。
```

コメントは行全体に適用されます。複数行のメモには、各行の先頭に `//` を付けます。字下げの空白が先頭にあってもコメントとして扱われます。

`本文 // メモ` のように文の途中へ置いた `//` と、全角の `／／` はコメントになりません。`/* メモ */` もThenのコメント記法には使えません。

行頭に `//` を本文として書きたい場合は、先頭にバックスラッシュを付けて `\//` と書きます。表示・書き出しではバックスラッシュが取り除かれ、`//` になります。

```text
\// この行はコメントではなく、本文として表示・出力される。
```

### ルビ

読みを付けたい文字を、`[本文(rb,読み)]` の形で囲みます。たとえば `[東京(rb,とうきょう)]` と書くと、「東京」全体に「とうきょう」というルビが付きます。

```text
　彼女は[東京(rb,とうきょう)]へ向かった。
```

一字ずつ読みを対応させたいときは、読みを空白で区切ります。`[東京(rb,とう きょう)]` なら、「東」に「とう」、「京」に「きょう」が付きます。本文が2文字以上で、空白で区切った読みの数と本文の文字数が一致するときに、この扱いになります。一致しない場合は、語全体へのルビとして扱われます。

### 圏点・傍点

文字の脇に点を付けて強調するときは、`[本文(em,goma)]` と書きます。`goma` はごま形の点、`dot` は丸い点です。

```text
　これは[絶対に秘密(em,goma)]だ。
　彼は[その一言(em,dot)]を忘れなかった。
```

`[本文(em)]` と `[本文(em,auto)]` も使えます。現在の表示・印刷用HTMLでは、`auto` もごま形の点になります。AIに指定するときは、点の形が分かる `goma` または `dot` を使うと明確です。

### 縦中横

縦書きの中で数字などを横並びにしたいときは、`[本文(tcy)]` と書きます。たとえば `[12(tcy)]` は、「12」を横に並べて表示する指定です。

```text
　締切は[12(tcy)]日だ。
　彼は[!?(tcy)]と書かれた紙を差し出した。
```

現在の編集画面で縦中横として扱われるのは4文字までです。5文字以上は縦中横としてまとめられないため、AIには短い数字や記号だけを対象にするよう指定します。

### 行揃え

行の先頭に `[(al:start)]`、`[(al:center)]`、`[(al:end)]` を置くと、その行の揃え方を指定できます。文字の一部分を囲む記法とは異なり、行全体に適用されます。

```text
[(al:start)]行頭に寄せる文
[(al:center)]中央に置く文
[(al:end)]行末に寄せる文
```

縦書きでは、`start` は上寄せの「天付き」、`end` は下寄せの「地付き」です。横書きでは、それぞれ左寄せと右寄せになります。`center` はどちらでも中央揃えです。

記号だけの行にして次の行へ効かせる書き方はせず、揃えたい文と同じ行に置きます。

## 既存原稿で使える互換記法

### 青空文庫形式のルビと圏点

Thenは、次の形式も読み取れます。Thenだけの独自記法ではありませんが、既存原稿を読むために覚えておくと便利です。

| 用途 | 記法の例 | 意味 |
| --- | --- | --- |
| 範囲を明示するルビ | `｜東京《とうきょう》` | `｜` から `《` の直前までの文字にルビを付ける |
| 漢字に続けるルビ | `東京《とうきょう》` | 直前の連続する漢字などにルビを付ける |
| 圏点 | `《《大切な言葉》》` | 囲んだ文字を圏点で強調する |

範囲を示す `｜` は全角です。ひらがなや英字を含む語にルビを付ける場合は、`｜` で対象範囲を明示する形が使えます。

### 旧来の地付き

行頭の `>>` と `［＃地付き］` も、行末へ寄せる指定として使えます。

```text
>> 著者名
［＃地付き］著者名
```

AIに新しく書かせる原稿では、同じ意味の `[(al:end)]著者名` にそろえます。標準Markdownでは `>>` は引用の入れ子に使われますが、Thenでは地付きとして扱われるため、引用のつもりで使わないようにします。

青空文庫の注記すべてに対応しているわけではありません。たとえば `［＃改ページ］` を、Thenで使える改ページ命令としてAIに指定しないでください。

## Markdownとの違いと、書くときの注意

### HTMLコメントは行単位

Markdownで使われるHTMLコメントも利用できます。ただし、Thenでは行単位で判定されます。1行のコメントは、行頭を `<!--`、行末を `-->` にします。前後に字下げなどの空白があっても構いません。

```text
<!-- この行全体がコメントになる。 -->
```

複数行の場合も、開始を行頭、終了を行末に置きます。

```text
<!--
ここに複数行のメモを書く。
この範囲は本文に含まれない。
-->
```

`本文<!-- メモ -->本文` のような行内コメントは対象外です。閉じる `-->` が見つからない場合、その開始記号によるコメント化は行われません。新しい原稿では、基本の `//` にそろえると書き方を覚えやすくなります。

### コードの中では記法を解釈しない

閉じたコードブロックの中と行内コードの中では、ルビ・圏点・縦中横などの記法は、書いたとおりの文字として扱われます。コードブロック内の `//` や `<!-- -->` も、Thenのコメントにはなりません。

コードブロックには、バッククォート3個以上、またはチルダ3個以上のフェンスを使います。閉じるフェンスは、開始と同じ記号を同じ数以上並べます。Thenでは、閉じるフェンスがない場合はコードブロックになりません。行頭に半角スペースを4個置くだけのコードブロックにも対応していません。

### 記号・改行・重ね掛け

基本の独自記法に使う `[`、`]`、`(`、`)`、`,`、`:` と、`rb`、`em`、`tcy`、`al` などの英字は半角で書きます。ルビ・圏点・縦中横の囲みは改行をまたげません。

装飾の入れ子や重ね掛けは、表示・書き出しで完全に扱えるとは限りません。AIへの指定では、同じ文字に複数の装飾を重ねず、必要な装飾を一つ選ぶ形にします。

### 字下げ

字下げには、段落先頭の全角スペースを使います。字下げ専用の独自記号はありません。字下げが必要な原稿では、半角スペースやタブへ置き換えず、全角スペースをそのまま書きます。
