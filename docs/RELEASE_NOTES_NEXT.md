# 次回リリース告知（公開時に掲載）

## 重要: 更新前に共通資料・共通Canvasを退避してください

このバージョンから、共通資料と共通Canvasのサポートを終了します。

更新後にThenを初めて起動した時点で、旧版で作成した次のデータは完全に削除されます。Then内にバックアップや退避ファイルは残りません。

- 共通資料
- 共通Canvas
- 共通Canvasのゴミ箱
- 共通Canvasから作成した中間稿

必要なデータがある場合は、**このバージョンをインストール・起動する前に**、旧版のThenから内容を確認し、Then外へ書き出すかコピーしてください。

作品フォルダ内の資料、Canvas、Canvasのゴミ箱、中間稿は削除されません。今後の資料とCanvasはすべて各作品フォルダ内に保存され、作品フォルダと一緒に別端末へ移動できます。

## 新機能: コメント

行頭が `//` の行と `<!-- -->` で囲んだ行を、コメントとして扱うようになりました。コメントは文字数・アウトライン・校正・エクスポートから除かれます。`Ctrl+/` でコメントにする・戻す、`Ctrl+Shift+/` で表示・非表示を切り替えられます。

既存の原稿で、行頭が `//` の行を本文として書いている場合は、その行がコメントとして扱われ、エクスポートから外れます。本文として残すには行頭を `\//` に書き換えてください。

## 新機能: コードブロックと行内コード

`` ``` `` / `~~~` で囲んだコードブロックと、`` `…` `` の行内コードを本文と区別して扱うようになりました。コードの中では見出し・記法・コメントを解釈せず、等幅フォントと背景色で表示します。縦書きでは、コードも縦書きのまま表示・出力されます。

- 設定「文字数にコードを含める」で、コードを文字数から除けます（既定はオン）。
- コードブロック内では `Tab` / `Shift+Tab` で半角スペース4個分のインデントを増減できます。
- コードブロック内の `Ctrl+/` は無効です。ブロック全体を選ぶとブロックごとコメントにできます。

既存の原稿で ``` を本文の区切りなどに使っている場合、閉じる行があるとその間がコードとして扱われます。

## 新機能: AIとの会話

右サイドバーの「AI」で、執筆の相談や調べものをAIと会話できるようになりました。会話は作品ごとに保存され、続けて質問すると前のやりとりを踏まえて回答します。

- 接続先はGemini（Google）とOpenAIです。使うには、自分で取得したAPIキーを設定の「AI」タブで入れます。料金は接続先へ直接支払います。OpenAIは、ChatGPTの有料プランとは別にAPIの残高が必要です。
- 会話の種類は「相談」と「Web検索付き調査」です。Web検索付き調査はOpenAIだけで使え、回答に出典が付きます。
- 本文で範囲を選んで右クリックし「AIに渡す」を選ぶと、その文章がAIの質問欄に入ります。Ideaポップアップと Idea の断片からは「AIに聞く」で渡せます。どちらも、送る前に欄で確かめて書き足せます。
- 残したい回答は「資料に保存」で、選んだIdeaスレッドにMarkdown資料として入れられます。AIの回答がスレッドに勝手に並ぶことはありません。
- 送信中の停止、失敗後の再送、会話の名前変更と削除ができます。

接続先へ送られるのは、その会話のやりとりと、自分で欄に入れた文章だけです。ほかの原稿・Idea・資料をThenが自動で送ることはありません。APIキーはWindowsの資格情報マネージャーに保存し、作品フォルダや設定ファイルには書き込みません。作品フォルダをコピーすると会話と保存した資料も移りますが、キーは移らないため、別の端末では入れ直してください。

ローカルLLMとClaudeへの接続、GeminiのWeb検索付き調査は、この版にはありません。

## 変更: 画面からの外部への通信を制限

安全のため、アプリの画面からインターネットへ直接通信できないようにしました。AIとの通信は、Thenの本体が決まった接続先にだけ行います。Webの画像の表示とPDFへの出力、Vivliostyleによる組版はこれまでどおり動きます。
