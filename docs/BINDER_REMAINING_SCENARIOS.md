## まず、言葉を4つだけ

| 言葉 | 意味 |
|---|---|
| 素材の段 | 左のバインダーの真ん中の段。素材フォルダ（ふつうは「素材」）の中のノート・画像・PDF |
| 送る | ノートや画像を、別の作品かライブラリ直下へ移動・コピーすること |
| 行き先のないリンク | 指すノートがない `[[ ]]`。薄く描かれ、押しても開かない |
| ボードのゴミ箱 | Canvas で消したボードの置き場。Canvas のボード一覧の下のゴミ箱のボタンから開く |

したいことは3つ。

1. **ノートや画像を、ほかの作品へ送る（U5）。ノートにスターを付ける（U10）。** 今はどちらもできない。
2. **画像・PDF をまとめて動かす（Q4）。ライブラリ直下の資料の画像を木に出す（Q5）。** 今は1つずつで、直下の画像は見えない。
3. **ボードのゴミ箱を空にする。** 今は戻すしかなく、消したボードがずっと残る。

| M1・M2・M5 まとめて | ✅ Ctrl で選び、ドラッグか右クリックでまとめて |
| M3 原稿の段 | ➖ 動かない |
| R1・R2 直下の画像 | ✅ `資料/` に出て、開く・改名・削除・動かせる |
| G1〜G3 ゴミ箱 | ✅ 確認のあと OS のゴミ箱へ。戻せる |

- **ファイルが消える場面はない。** 送る・消すは、送り先か OS のゴミ箱に必ず残る。送る命令が途中で落ちたら、全部を元に戻して失敗にする。
- **作品の中の今の移動は変わらない。** 作品の外へ送る命令は別に作る。
