Thenで使う原稿として、基本はMarkdownで書いてください。独自記法が必要な箇所では、以下の形式を使ってください。

1. コメントアウト
   原稿に含めないメモは、独立した行の先頭に半角の「// 」を付ける。
   例：// この場面はあとで書き直す。
   複数行のメモには、各行の先頭に「// 」を付ける。字下げの空白の後でもよい。
   「本文 // メモ」、全角の「／／」、「/* メモ */」はコメントとして使わない。
   行頭の「//」を本文として書く場合は「\//」と書く。

2. ルビ
   語全体へのルビ：[東京(rb,とうきょう)]
   一字ずつのルビ：[東京(rb,とう きょう)]
   一字ずつ付ける場合は、本文を2文字以上とし、読みを半角スペースで区切って、本文の文字数と読みの個数を一致させる。

3. 圏点・傍点
   ごま形の点：[大切な言葉(em,goma)]
   丸い点：[大切な言葉(em,dot)]
   通常はgomaを使い、丸い点の指定がある場合にdotを使う。

4. 縦中横
   数字や記号を横並びにする：[12(tcy)]、[!?(tcy)]
   対象は4文字以内にする。

5. 行揃え
   行頭寄せ：[(al:start)]本文
   中央揃え：[(al:center)]本文
   行末寄せ：[(al:end)]本文
   縦書きではstartが天付き、endが地付き。横書きではstartが左寄せ、endが右寄せ。
   記号は揃えたい本文と同じ行の先頭に置く。次の行への指定には使わない。

6. HTMLコメントを使う場合
   1行なら「<!-- メモ -->」を独立した行に書く。
   複数行なら、開始行に「<!--」、終了行に「-->」を置き、その間にメモを書く。
   必ず閉じる。「本文<!-- メモ -->本文」のような行内コメントは使わない。
   通常のメモは1の「// 」にそろえる。

7. 記法の共通条件
   独自記法の角括弧・丸括弧・カンマ・コロン・英字は半角で書く。
   ルビ・圏点・縦中横の囲みは改行をまたがせない。
   装飾は入れ子にせず、同じ文字への重ね掛けを避ける。
   新しく書く原稿では、青空文庫形式のルビ・圏点や、旧来の地付き「>>」「［＃地付き］」を混在させず、上記の形式にそろえる。
   「［＃改ページ］」など、ここにない青空文庫注記をThenの命令として追加しない。
   字下げが必要な箇所は、行頭に全角スペースを書く。
   コードブロックと行内コードの中では、独自記法は文字どおりに扱われる。コードブロック内の「//」やHTMLコメントもThenのコメントにはならない。
   コードブロックはバッククォートまたはチルダを3個以上並べたフェンスで囲み、同じ記号を開始と同じ数以上並べて必ず閉じる。半角スペース4個の字下げをコードブロックの代わりにしない。
