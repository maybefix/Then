# Ticket sample plugin

Then Plugin API v1で、プロジェクト単位のチケット管理を実装したサンプルです。

## 導入

1. Thenで `Ctrl+P` を押す
2. 「プラグインを管理…」を開く
3. 「プラグインを追加…」を選ぶ
4. この `ticket` フォルダを指定する

## 含まれる実装

- トップバーの固有アイコンから開く全画面カンバン
- Trello型のコンパクトな列とカード配置
- 各列下部から開く作成モーダルと、カードをクリックして開く詳細モーダル
- 並び順とは独立し、削除後も再利用しない固定の自動付番ID（`#001` など）
- 種別、状態、対象、詳細の編集
- 未着手／進行中／完了のドラッグ&ドロップと手動並べ替え
- チケットの追加、検索、削除、状態変更
- 右サイドバーの「未着手」「進行中」2ビュー
- 右サイドバーのカード、現在チケットのステータスバー項目、選択範囲から開く共通の全面詳細モーダル（本文画面を維持）
- 未着手ビューから画面遷移なしで開く新規作成モーダルと、各ビュー上での状態変更
- ボード上の小さなゴミ箱ボタンと、削除したチケットの復旧・確認付き完全削除
- 「現在のチケット」の選択と、本文画面下部中央へのID・タイトル表示
- プロジェクトごとの `then.storage` 保存と、保存処理中でも混線しないプロジェクト切り替え時の自動再読み込み
- 選択中の本文を詳細へ入れて作成モーダルを開く右クリックメニュー／コマンド（`Mod+Alt+T`）。タイトルは手動入力
- Thenの明色／暗色テーマへの自動追従

通常の「削除」はチケットへ削除日時を付けてゴミ箱へ移動する論理削除です。復旧時は元の状態の末尾へ戻り、固定IDは変わりません。完全削除した場合も、そのID番号を新しいチケットへ再利用しません。

本文やASTへTicket情報は書き込みません。保存先はThenが管理するプロジェクト別のプラグイン保存領域です。
