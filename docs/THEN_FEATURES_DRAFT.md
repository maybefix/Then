## 1. Thenの概要
// Thenは、日本語の小説やシナリオを書くためのWindows向けエディタ。
// 原稿の執筆、構想や資料の整理、校正、書き出しを行える。
// 原稿はMarkdown（.md）またはテキスト（.txt）で保存する。

## 2. 起動と作品の管理

### 起動ポータル
// 最近開いたライブラリや作品を選び、作業を再開する。
// 新しいライブラリの作成や、既存の作品フォルダの取り込みを行える。

### ライブラリと作品
// ライブラリは複数の作品をまとめるフォルダ。作品ごとに原稿やThenの管理データを持つ。
// 作品一覧はカード表示と表表示を切り替えられる。
// 作品名・あらすじでの検索、制作状況での絞り込み、更新日・名前・字数での並べ替えに対応する。
// 作品ごとの文字数と原稿の進捗を確認できる。

### 原稿の作成と保存
// 新規原稿の作成、既存ファイルを開く、保存、別名で保存を行える。
// 編集後は自動保存され、画面下部に保存状態を表示する。
// 保存先を持たない新規原稿では、ファイル名と保存先を指定する。

## 3. 画面とファイル操作

### 作業画面
// 本文、キャンバス、エクスポート、チェックポイントを切り替えて使う。
// 左側でファイルや検索結果を扱い、右側でIdea、Plot、校正、中間稿を参照する。
// 編集メモ：右ペインの入口には「バインダー」という表示もある。公開原稿の呼称は画面と合わせる。

### ファイルとフォルダ
// ファイルやフォルダの作成、名前変更、移動、並べ替え、削除を行える。
// 複数ファイルを選び、まとめて並べ替えたり別フォルダへ移動したりできる。
// 削除した原稿はThen管理用のTrashへ移動する。
// ファイルツリーを進捗（未着手・執筆中・推敲中・完了・アーカイブ）で絞り込める。アーカイブは通常表示から外れる。

### パンくずとタブ
// パンくずから現在のファイルの階層を確認し、フォルダやファイルを選べる。
// 複数の原稿をタブで開き、ドラッグで並べ替えられる。
// タブを切り替えて戻ると、カーソル位置と表示位置を復元する。
// タブの一括クローズ、閉じたタブを開き直す操作、パスのコピーに対応する。
// 作品ごとに開いていたタブを記憶する。

### ファイルの進捗とプロパティ
// 原稿ファイルに進捗ラベルを付け、執筆状況を管理する。
// 原稿冒頭のフロントマターは、本文と分けたプロパティ欄で編集できる。

## 4. 本文の執筆と表示

### 縦書きと横書き
// 本文の組方向を縦書き・横書きから選べる。
// 本文フォント、見出し・太字のフォント、文字サイズ、行間、表示幅を調整できる。

### 連続表示とページ表示
// 本文を連続して表示する方式と、ページ単位で表示する方式を選べる。
// ページ表示では、右から左への横送りと上から下への縦送りを選べる。
// 編集メモ：編集画面のページ表示と、書き出しの組版プレビューは節を分けて説明する。

### タイプライタースクロール
// 入力している行を画面内の一定位置に保つ。
// オン・オフ、固定位置、目安となる中央線の表示を変更できる。

### 表示補助と文字数
// 行番号、改行記号、現在行のハイライト、会話文の色分けを設定できる。
// ステータスバーで文字数を確認でき、空白とコードを数に含めるか選べる。
// コメントは文字数に含めない。

## 5. MarkdownとThenの記法

### Markdown
// 見出し、太字、引用、リスト、表、行内コード、コードブロックを使える。
// 表の挿入と列の揃え方の指定は、コマンドパレットからも行える。
// 編集メモ：対応する記法と出力先ごとの表示差は、短い実例を使って補足する。

### ルビ・圏点・縦中横
// ルビは `[東京(rb,とうきょう)]` の形で指定する。
// 圏点は `[本文(em,goma)]`、丸い点は `[本文(em,dot)]` の形で指定する。
// 縦中横は `[12(tcy)]` の形で指定する。編集画面でまとめる文字数は4文字まで。
// 青空文庫形式のルビや圏点にも対応する。
// 選択した文字にコマンドを適用できる。改行をまたぐ範囲には適用しない。

### 行揃え
// `[(al:start)]本文`、`[(al:center)]本文`、`[(al:end)]本文` で行の揃え方を指定する。
// 縦書きでは天付き・中央・地付き、横書きでは左寄せ・中央・右寄せになる。

### コメントアウト
// 原稿に含めないメモは、行頭に半角のコメント記号と空白を置く。複数行では各行に付ける。
// 記法例：`// 後で書き直す箇所のメモ`
// 字下げの空白の後でも使える。行の途中に置いた記号はコメントにならない。
// 行頭の記号を本文として残す場合は `\//` と書く。
// コメントは文字数、見出しアウトライン、校正、PDF・DOCX・投稿用テキストから除外する。
// コメントの表示・非表示を切り替えられる。検索・置換では、コメントを含めるか選べる。

### コード
// 行内コードとコードブロックの中では、ルビやコメントなどを解釈せず、記述をそのまま扱う。
// コードは等幅フォントと背景色で表示する。縦書きではコードも縦書きになる。
// コードブロック内のTab・Shift+Tabでインデントを増減できる。

### 画像
// `![説明](画像の場所)` の形で画像を指定する。
// 作品フォルダ内の相対パスと、HTTPSの画像URLを使える。
// 編集中は記法を表示し、マウスを重ねると画像をプレビューする。
// PDFでは図版や行内画像として出力する。図版の説明をキャプションにする設定がある。
// DOCXでは画像の代わりに説明文を出力する。投稿用テキストでは画像記法を残す。

## 6. 移動・検索・原稿の整理

### 見出しアウトライン
// 原稿や作品内の見出しを階層表示し、見出しの位置へ移動できる。
// 見出しをドラッグして、配下の文章を同じファイル内や別ファイルへ移動できる。
// 一つのセクションを別ファイルとして切り出せる。

### 検索と置換
// 現在のファイル、作品内、ライブラリ内を対象に検索できる。
// 検索結果から該当箇所へ移動できる。正規表現による検索にも対応する。
// ファイル内や作品内で置換を行える。作品内の一括置換では実行前に確認する。
// コメントは通常対象から外し、必要なときに検索・置換へ含める。

### 原稿を整える
// 段落冒頭の字下げと、感嘆符・疑問符の後の一字空けをまとめて適用できる。
// 文書全体か選択範囲の行を対象にし、変更件数を確認して実行する。
// 適用後は元に戻す操作で取り消せる。

## 7. Ideaと資料

### Ideaの記録と整理
// メモをIdea断片として保存し、スレッドにまとめる。
// スレッドの作成、名前変更、スター、検索、断片の編集・移動・並べ替えを行える。
// Ideaと資料を同じスレッド内に並べられる。
// クイック追加から、右ペインを開かずにメモを保存できる。
// Ideaの管理単位は作品ごと、または全作品で共有から選べる。

### 資料の取り込み
// テキスト、Markdown、画像、PDFを作品の資料として取り込める。
// 新しいテキスト・Markdown資料を作成できる。
// 同じ資料を複数のスレッドから参照できる。
// 資料は作品フォルダに保存する。共通資料は現在の機能に含まれない。

### 本文上のカード
// Ideaや資料を、本文の上に浮かぶカードとして開ける。
// カードの移動、サイズ変更、ピン留め、折りたたみを行える。
// テキスト資料の編集、画像のズーム、PDFのページ操作に対応する。
// 開いているカードを左側の一覧から確認できる。
// スレッドから資料の参照を外す操作と、資料ファイル自体を削除する操作がある。

## 8. Plot
// 章とセクションのカードで物語の構成を整理する。
// タイトルと本文を編集し、章やセクションの順序をドラッグで変更できる。
// セクションを別の章へ移動し、章を折りたためる。
// 資料を関連付け、構成を考えながら参照できる。

## 9. キャンバス（Idea Board）

### Boardとカード
// 作品ごとに複数のBoardを作成し、テキストや資料のカードを配置する。
// Boardの名前や順序を変更し、ゴミ箱へ移したBoardを復元できる。
// カードの編集、移動、サイズ変更、複製、色変更、複数選択に対応する。
// 盤面の移動、拡大・縮小、全体表示を行える。

### 接続線・スレッド・グループ
// カードを線や矢印で結び、接続線にラベルを付ける。
// カードをスレッドとして縦にまとめ、折りたためる。
// 複数のカードをグループにまとめて移動できる。
// 選択したテキストカードをIdeaやPlotへ送れる。

### 保存と表示設定
// Boardは作品フォルダ内に保存する。共通Canvasは現在の機能に含まれない。
// カードの既定フォント・組方向や、別ウィンドウで開く設定を変更できる。

## 10. 中間稿
// Boardのテキストカードを並べ、一続きの文章にする。
// 順序の調整と、生成対象に含めるカードの選択ができる。
// 生成した文章を編集・コピーし、テキストファイルへ書き出せる。
// Canvasから再生成すると新しい版を作り、以前の版も残す。
// 中間稿を編集しても、Canvasのカードや本文の原稿へは自動反映しない。

## 11. 校正と辞書
// 日本語の表記ゆれ、重複・冗長表現、約物、敬語などを確認する。
// 異字同訓、同音異義語、主述の対応なども校正対象に含む。
// 指摘を選んで本文の該当箇所へ移動し、候補がある場合は置換できる。
// 固有名詞や作品内の用語を校正辞書に登録できる。
// ルールや判定の目安を変更し、会話文を対象から外す設定も使える。
// 校正処理はアプリ内で行う。
// 編集メモ：指摘の種類は具体例を一つずつ添える。文脈で判断が変わる例も載せる。

## 12. チェックポイント
// 作品内の原稿と並び順を、名前やメモを付けた保存点として残す。
// 保存点と現在の原稿、または二つの保存点を比較できる。
// ファイルごとの変更、追加、削除、移動を確認できる。
// 全体の復元と、選んだファイル・フォルダだけの復元に対応する。
// 競合時は置き換え、別ファイルとして復元、スキップから選ぶ。復元前の状態は自動退避する。
// 画像・PDFなども含む作品フォルダ全体のバックアップは、別途行う必要がある。

## 13. 書き出し

### 原稿の選択と順序
// 複数ファイルを選び、順序を指定して一つの文書へまとめる。
// 原稿の本文を編集する画面と、出力用の設定・プレビューを分けて使う。

### PDFとDOCX
// 用紙サイズ、組方向、余白、フォント、段組みを設定できる。
// ヘッダー、フッター、ノンブル、ファイルごとの開始方法を指定できる。
// 表紙と目次を付けられる。表紙には文字や画像を使える。
// プレビューで確認し、PDFまたはDOCXとして保存する。
// DOCXの目次のページ番号は、Word側でフィールドを更新する。
// 編集メモ：PDFとDOCXの表示差、画像の扱いは出力例で示す。

### Web小説用テキスト
// カクヨム、小説家になろう、プレーンテキスト向けに変換する。
// 投稿先に合わせてルビや圏点を変換し、見出しの残し方を選べる。
// ファイル間の区切りと改行コードを設定できる。
// プレビューと変換時の警告を確認し、クリップボードへコピーするか、テキストファイルへ保存する。
// 投稿サイトへのアップロードは利用者が行う。

## 14. 設定とコマンド

### 外観と作業領域
// テーマ、UIフォント、表示倍率を変更できる。
// サイドペインとタブバーの表示方法を調整できる。
// 集中表示で本文の作業領域を広げられる。完全フルスクリーンを使う設定もある。
// 設定は外観、本文、ファイル、キャンバス、出力の項目に分かれる。

### 主なショートカット
// - Ctrl+P：コマンドパレット。
// - Ctrl+Alt+I：Ideaへメモを追加。
// - Ctrl+B：太字。Ctrl+I：圏点。
// - Ctrl+1〜6：見出し。Ctrl+0：見出し解除。
// - Ctrl+/：行をコメントにする・戻す。
// - Ctrl+Shift+/：コメントの表示・非表示。
// - Ctrl+Tab／Ctrl+Shift+Tab：次・前のタブへ移動。
// - Ctrl+W：タブを閉じる。Ctrl+Shift+T：閉じたタブを開き直す。
// 編集メモ：全ショートカットの一覧は、操作説明の確定後に別表へまとめる。

### プラグイン
// プラグイン管理画面から追加、権限の確認、有効・無効の切り替えを行える。
// プラグインはペイン、作業画面、コマンド、ステータスバー項目などを追加できる。
// 編集メモ：導入操作の説明と、開発者向けのPlugin API資料を分ける。

## 15. データの保存と持ち運び
// 原稿と作品固有の管理データは作品フォルダに保存する。
// 作品を別端末へ移す場合は、管理用の `.then` を含めてフォルダをコピーする。
// テーマ、ウィンドウ、タブなどの端末側の設定は、作品フォルダとは別に保存する。
// 外部の同期サービスを使う場合は、保存と同期の完了を確認してから端末を切り替える。
