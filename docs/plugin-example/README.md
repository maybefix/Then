# Selection Notes sample plugin

Then Plugin API v1の主要機能を、実際に使える「本文へのノート」機能としてまとめたサンプルです。

## 機能

- 現在の選択範囲とプロジェクト相対パスのプレビュー
- 本文やASTを書き換えない永続アンカー付きノート
- ノート、引用本文、ファイルパスの検索
- 保存済みアンカーへの移動と、安全な二段階削除
- 文書変更通知を受けたアンカー追従状態の表示
- プロジェクト単位のノート保存
- `Mod+Alt+M`: 選択範囲をすぐ記録
- `Mod+Alt+J`: 次のノートへ移動

## 試し方

1. ThenでCtrl+Pを押し、「プラグインを管理…」を開いて「プラグインを追加…」を実行します。
2. この `plugin-example` フォルダを選択します。
3. 表示された権限を確認して導入します。
4. 右サイドバーの「Selection Notes」タブを開きます。

プラグイン本体を削除する場合は、「プラグインを管理…」の一覧でSelection Notesの「削除」を実行します。プロジェクトに保存されたノートとアンカーは残るため、再導入後に続きから利用できます。
