## まず、言葉を3つだけ

| 言葉 | 意味 |
|---|---|
| 投稿 | 右のペイン「アイデア」の1件。ライブラリ全体で共有する |
| 投稿のカード | Canvas のカード。投稿の ID だけを覚えていて、本文は投稿から映す（前回の作業で作った） |
| 置き換え | テキストカードを、同じ場所・大きさ・色の投稿のカードに変えること |

したいことは3つ。

1. **投稿の側から、その投稿のカードがどのボードにあるかを見て、行けるようにする。**
2. **アイデアのペインの投稿を、Canvas へドラッグして置けるようにする。**
3. **Canvas の「投稿にする」で、カードを投稿のカードに変える**（いまはテキストのまま残り、同じ文が2つになる）。

---

## 場面の舞台

ライブラリ「本棚」を使う。

- 作品A・作品B と、ライブラリ直下がある。
- 投稿: P1「灯台の夢」（作品A）、P2「港で拾った言葉」（作品B）、P3「夜の郵便局」（ノートにした）、P4「続き：波の音」（P1 への返信）
- ボード
  - 作品A の「構想」: P1 のカード
  - 作品B の「取材」: P1 と P2 のカード
  - ライブラリ直下の「全体」: P1 のカード
  - 作品A のゴミ箱にあるボード「古い構想」: P1 のカード
- 作品A を開いていて、真ん中に「構想」（埋め込みの Canvas）、右にアイデアのペインが出ている。

記号: ✅ = できる・変わる　➖ = そのまま・できない　⚠️ = できるが、何かが見えなくなる・変わる
