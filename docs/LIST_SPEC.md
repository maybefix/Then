# Then 箇条書き 仕様メモ

作成日: 2026-10-03
状態: 実装済み

## 1. 判定

- `- ` / `* ` / `+ ` / `1. ` / `1) ` で始まる行（記号の後に半角空白1個以上）を箇条書きの行とする。
- 行頭の字下げでレベルを決める。半角空白2個で1段、タブは空白2個ぶんと数える。最大はレベル6（それ以上の字下げもレベル6扱い）。
- 判定は `src/editor/ast/documentAst.ts`。

## 2. 表示

- 行間は通常の行と同じ（`--editor-line-height` に従う）。
- ぶら下げインデント: 折り返した2行目（縦書きでは2列目）以降を、1行目の本文の頭に揃える。
  - 行頭の字下げ＋マーカー（`  - ` など）を固定幅の箱（`.list-marker`）に入れ、2行目以降は同じ幅だけ下げる。箱の幅は「文字数 × 1ch」。空白・記号・数字はどれも1ch以内なので、フォントによらず箱からはみ出さない。
  - マーカー部分には禁則などの他の装飾をかけない（箱が分割されるため）。
- レベルごとの字下げ: レベル0は0.6em、以降0.9em刻み（レベル6で6em）。
- マーカーは文字のまま表示する（`・` などへの置き換えはしない）。
- 実装: `src/VerticalTextEditor.tsx`（`listMarkerRange`、`pushLineDecos`）、`src/App.css`（`p.list-line`）。

## 3. Tab / Shift+Tab

- 箇条書きの行で `Tab` を押すと1段深く（行頭に半角空白2個を足す）、`Shift+Tab` で1段浅く（行頭の字下げを空白2個ぶん取り除く）する。キャレットの位置は行内のどこでもよい。
- 子の項目（後に続く、より深い箇条書きの行）も一緒に動かし、入れ子の形を保つ。空行は挟まっていてもよい。
- 複数行を選択しているときは、選択範囲内の箇条書きの行（とその子）をまとめて動かす。普通の行は動かさない。
- 次のときは何もしない（キーは消費する）。
  - レベル0で `Shift+Tab`。箇条書きを普通の行に戻すことはしない。
  - レベル6で `Tab`。
  - **段を飛ばす**とき: 直前の項目より2段以上深くなる `Tab`。直前の空行でない行が箇条書きでなければ（リストの先頭の項目なら）、レベル0より深くできない。
- 番号付きの項目も同じように動かす。番号の振り直しはしない。
- `Tab` 1回を `Ctrl+Z` 1回で戻せる（前後の入力と履歴をまとめない）。
- 箇条書きでない行、表（セル移動）、コードブロック（空白4個）、日本語入力の変換中では、この処理をしない。
- 実装: `src/VerticalTextEditor.tsx` の `handleListIndent`。

## 4. 書き出し

- Word では箇条書きの段落も通常の段落と同じ既定の行間を使う。特別な体裁はつけていない。
